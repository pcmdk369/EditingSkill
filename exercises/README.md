# Practical Exercise Library

## Foundation
1. Identify resolution, aspect ratio, frame rate and codec from sample media.
2. Sort assets into a consistent folder structure and create a backup.
3. Compare raster and vector artwork; export appropriate formats.

## Beginner
4. Create a 30-second montage with clean cuts.
5. Add a title, lower third and music fade.
6. Export two versions with different aspect ratios.

## Intermediate
7. Edit a two-camera interview with synchronized audio.
8. Create a short sequence using J-cuts and L-cuts.
9. Animate a title with keyframes and easing.
10. Create captions and check timing.

## Advanced
11. Match shots using scopes and color correction.
12. Build a green-screen composite.
13. Design a soundscape with dialogue, ambience and effects.
14. Create a motion-graphics explainer.

## Expert and Master
15. Edit a narrative scene from coverage.
16. Produce a 60–90 second advertisement from a client brief.
17. Finish a documentary short with captions and delivery versions.
18. Design a full post-production workflow and QC report.

## AI and automation
19. Compare human and AI transcripts and correct errors.
20. Build a batch transcode workflow and verify outputs.
21. Create an AI-assisted rough-cut plan with human approval gates.
22. Test generated media for artifacts, continuity and rights compliance.

Each exercise should include source assets or clearly stated asset requirements, learning objectives, steps, expected result, rubric and reflection questions.
