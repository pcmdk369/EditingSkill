# CT-16 Professional Lab 02 — Mix Translation and Mastering Reference Audit

- Course: CT-16 — Music Production & Audio Mixing
- Level: Expert / Professional
- Estimated time: 4–6 hours
- Environment: DAW, loudness/true-peak meter, headphones, monitors and alternate playback devices
- Lab status: Authored procedure; no acoustic room calibration or commercial mastering certification is claimed

## Brief
Mix a learner-created 60–120 second music production and prepare a master plus stems. Evaluate translation across playback systems, compare to licensed references at matched loudness and document technical decisions.

## Learning objectives
Separate mix decisions from mastering, use references without copying, diagnose translation problems, measure delivery properties and preserve a reproducible session.

## Inputs
Original or properly licensed multitracks, arrangement notes, client delivery specification and authorized reference tracks. Record rights and exact master version. Do not distribute reference audio in the delivery package unless licensed.

## Procedure
1. Back up the session and consolidate media.
2. Check tempo, sample rate, bit depth and routing.
3. Establish static balance before detailed processing.
4. Check mono compatibility, phase and low-frequency interactions.
5. Apply EQ, dynamics, automation and spatial effects with documented intent.
6. Compare with one or more authorized references at matched perceived loudness.
7. Test on headphones, monitors and at least one alternate consumer playback device.
8. Record translation problems: vocal balance, bass translation, harshness, stereo width and transient clarity.
9. Revise the mix, preserving a pre-master print.
10. Master a copy to the supplied target; do not invent a streaming/broadcast target if none is provided.
11. Measure integrated loudness, sample peak and true peak using a stated meter/standard.
12. Export master and stems with documented processing boundaries.
13. Re-import stems and verify timing and expected recombination behavior.
14. Reopen final files and listen to complete playback.
15. Deliver session, master, stems, reference notes, measurement report and rights manifest.

## Validation
| Test | Method | Pass condition |
|---|---|---|
| Session | Open from package | No missing media |
| Phase/mono | Fold-down check | No destructive cancellation |
| Translation | Multiple playback systems | No severe balance failure |
| Reference | Loudness-matched comparison | Decisions documented |
| Loudness | Full-program meter | Meets supplied brief |
| Peak | Sample/true-peak meter | Meets supplied brief |
| Stems | Re-import | Start/end and processing notes correct |
| Rights | Source audit | All used material authorized |

## Troubleshooting
- Bass disappears on small speakers: inspect arrangement, harmonics and low-mid balance.
- Master pumps: revisit mix dynamics and limiter input.
- Stereo collapses: inspect phase and width processing.
- Stem sum differs: document master-bus nonlinear processing and print boundaries.
- Loudness target missed: revise gain/dynamics without clipping or distorting.

## Deliverables
Pre-master mix, final master, stems, DAW session, measurement report, translation notes, reference log, rights register and delivery manifest.

## Assessment — 100 points
Session/routing 10; mix balance 20; translation diagnosis 15; mastering decisions 15; measurement compliance 15; stem integrity 10; rights/provenance 5; handoff 10. Pass 80/100.
