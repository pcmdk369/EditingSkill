# CT-19 Capstone — Responsive Motion Identity and Explainer

- Level: Master / Professional Practice
- Estimated time: 12–18 hours
- Status: Brief authored; learner execution and review not evidenced

## Brief
Create a 15–30 second motion-graphics explainer or identity package with a coherent visual system and at least two aspect-ratio adaptations.

## Deliverables
- audience/message brief and approved copy;
- static style frames and storyboard;
- typography/color/shape/motion guide;
- editable project and reusable components;
- vertical and landscape exports;
- data source if infographic content is used;
- accessibility/contrast/reduced-motion notes;
- font/asset license and dependency register;
- AI provenance/correction log where applicable;
- QC report, manifest and reflection.

## Mandatory gates
Text and data must be accurate; assets licensed; dependencies documented; no misleading scale or unsupported claims.

## Rubric — 100 points
| Criterion | Points |
|---|---:|
| Message and visual hierarchy | 15 |
| Typography and readability | 15 |
| Motion craft and timing | 15 |
| Data/claim accuracy | 10 |
| Responsive adaptation | 15 |
| Accessibility | 10 |
| Rights/provenance | 5 |
| Technical export/handoff | 10 |
| Reflection | 5 |

Pass: 80/100. Factual accuracy, rights and technical delivery are mandatory.

## Review
Reviewer checks copy/data, playback readability, motion consistency, responsive outputs, licenses, dependencies and full exports. Actual learner artifacts and review evidence are required.
