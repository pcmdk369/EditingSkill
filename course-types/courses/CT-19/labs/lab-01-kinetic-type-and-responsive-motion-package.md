# CT-19 Professional Lab 01 — Kinetic Type and Responsive Motion Package

- Level: Advanced / Professional
- Estimated time: 4–6 hours
- Environment: Motion graphics application; record OS/app/version, frame rate and canvas
- Lab status: Authored procedure; not executed in this session

## Brief
Create a 15-second typographic explainer with a title, three information beats and a final CTA. Adapt it to vertical and landscape formats while preserving readability.

## Prerequisites
Complete CT-19 Lessons 01–05. Use approved copy, licensed fonts and authorized visual assets.

## Procedure
1. Confirm message, audience, copy and delivery formats.
2. Proofread all text and record source/approval.
3. Design static style frame and hierarchy.
4. Establish type scale, spacing and easing tokens.
5. Animate title and information beats with adequate reading holds.
6. Use shapes/masks to reveal information where useful.
7. Build reusable components for text and accents.
8. Adapt layout and timing to vertical/landscape canvases.
9. Check contrast, reduced-motion alternatives and text readability.
10. Render proof in each format.
11. Inspect edges, frame rate, alpha and text at actual size.
12. Package project, fonts/assets (where permitted), dependencies and manifest.

## Expected artifacts
Style frame, motion guide, 15-second vertical and landscape exports, editable project, copy approval, font/asset license notes and QC report.

## Validation
| Test | Method | Expected result |
|---|---|---|
| Copy | Compare to approved text | No typo or meaning change |
| Readability | Normal-speed playback | All text can be read |
| Motion | Sequence review | Clear hierarchy and consistent easing |
| Responsive layout | Compare formats | No clipped text/controls |
| Accessibility | Contrast/reduced motion review | Readable alternatives |
| Export | Metadata and playback | Meets brief |
| Handoff | Reopen project | Dependencies documented |

## Troubleshooting
Text too fast: extend hold or reduce copy. Layout collision: redesign per aspect ratio. Expression failure: use fallback/manual control. Alpha fringe: verify premultiplication and render proof.

## Assessment — 100 points
Design hierarchy 15; typography/readability 20; motion/easing 15; responsive adaptation 15; accessibility 10; technical export 10; licensing/dependencies 5; documentation/handoff 10. Pass 80/100.

## Handoff
Submit style frame, motion guide, both exports, editable project, rights/dependency list and QC report.
