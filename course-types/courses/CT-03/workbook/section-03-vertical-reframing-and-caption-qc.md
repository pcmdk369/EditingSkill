## B. Crop geometry worksheet

For a target aspect ratio narrower than the source, a first crop estimate that retains full source height is:

`crop width = source height × target aspect ratio`

For a target wider than the source, a first crop estimate that retains full source width is:

`crop height = source width ÷ target aspect ratio`

|---|---|

**Reminder:** Geometry does not determine the best composition. Inspect the actual subject, action and context.

### Continuity review

- Does the subject jump across the frame between adjacent shots?
- Are eyeline and screen direction consistent?
- Is headroom/lead room intentional?
- Does a crop cut off a hand, product, gesture or evidence?
- Does automated tracking drift during occlusion?
- Would an alternate shot or a static composition be clearer?
