# CT-01 — Foundation and Beginner Knowledge Assessment

Suggested time: 20 minutes. Written assessment: 20 points. Pass: 16/20.

## Questions (2 points each)
1. Explain the difference between source media, a project file and an export.
2. Name four details to record in a project brief.
3. Why copy and verify media before editing?
4. Explain container versus codec.
5. What does a proxy do, and why label it?
6. What does the playhead indicate?
7. Explain insert versus overwrite.
8. Explain ripple delete versus roll edit.
9. What is a slip edit used for?
10. Name two continuity details to check between shots.

## Answer key and marking guide
1. Source media are original assets; project file stores edit instructions/references; export is the rendered playable output.
2. Any four: audience, purpose, platform, duration, aspect ratio, resolution, frame rate, format, deadline, rights and constraints.
3. Protects originals, reduces risk of card loss or accidental modification and provides stable working copies.
4. Container is the wrapper; codec encodes/decodes the media streams.
5. Proxy is an easier-to-edit copy for performance; labeling prevents confusion with the original/master.
6. Current timeline position.
7. Insert adds material and shifts later content; overwrite replaces material in the target range.
8. Ripple delete removes material and closes the gap; roll moves the boundary between adjacent clips while preserving total duration.
9. Changes source frames shown without changing timeline position or duration.
10. Any two: screen direction, action phase, object position, eyeline, geography, lighting, background or prop state.

## Practical assessment
Create a 30–45 second story using at least five shots. Submit editable project, export, source inventory and a one-page edit decision note.

### Practical rubric — 40 points
| Criterion | Points | Full-credit standard |
|---|---:|---|
| Organization and source safety | 8 | Clear folders, originals preserved, inventory complete |
| Story clarity | 8 | Understandable beginning, development and ending |
| Editing craft | 8 | Deliberate trims, no accidental gaps, suitable pacing |
| Continuity and sync | 6 | Action and audio remain coherent |
| Technical delivery | 6 | Export plays and matches documented settings |
| Reflection | 4 | Explains at least three creative/technical decisions |

Pass: 32/40. Missing project file, corrupt export or rights violation requires resubmission regardless of score.

Give criterion-specific feedback. Learner corrects failed criteria and submits affected components plus a complete playback check. Watching lessons alone does not qualify for completion.
