# CT-01 Software Lab 03 — CapCut Mobile: Smartphone Editing and Export

**Track:** Android/iOS mobile editor  
**Reference baseline:** CapCut Help Center guidance checked 16 November 2026. Features vary by app version, device hardware, source media and region.  
**Practice time:** 90–120 minutes  
**Prerequisites:** CT-01 Lessons 01–08  
**Assets:** Self-recorded clips, original voice-over and music you own or are licensed to use.

## Outcomes
Create a mobile project, assemble a vertical short, add titles/captions and sound, export within device limits, and preserve the editable draft.

## Important limitations
CapCut's export resolution choices are conditional. Its Help Center states that mobile 2K/4K options depend on device capability, source resolution, region and app version; not every Android phone exposes 4K. Never promise a resolution option without checking the actual device. CapCut also documents that projects/drafts and exported videos are different: export creates a rendered video, not a fully editable project transfer.

## Key terms
- Draft/project: editable timeline and settings saved in CapCut.
- Overlay: visual layer placed above the main video.
- Split: divides a clip at the playhead.
- Keyframe: stores a property value at a chosen time.
- Auto captions: speech recognition-generated caption draft that requires proofreading.
- Export: renders the edit to a playable video file.

## Lab A — Prepare phone and project
1. Check free storage and battery; close unnecessary apps.
2. Keep original clips in a stable device folder or backed-up location.
3. Open CapCut and create a new project.
4. Select only practice media you own or have permission to use.
5. Set the intended canvas/aspect ratio to 9:16 if the deliverable is a vertical short. The location of the ratio control can change by version.
6. Save the draft and confirm it appears in the project/draft list.

## Lab B — Build the story
1. Place the strongest moment near the beginning.
2. Trim dead time while preserving context.
3. Split clips at clear action or speech boundaries.
4. Reorder clips to create setup, development and payoff.
5. Add a small number of purposeful overlays or B-roll clips.
6. Reframe each shot so faces, products and action remain visible in vertical orientation.
7. Add a title with sufficient contrast and leave room for platform interface overlays.
8. If using auto captions, generate them and manually correct every name, number and technical term.

## Lab C — Sound and motion
1. Set dialogue/voice-over as the main audio.
2. Reduce music so speech remains intelligible.
3. Add fades where abrupt audio cuts occur.
4. Use keyframes only where motion improves the story; inspect the beginning and end of each animated property.
5. Review the whole edit with headphones at a safe listening level.

## Lab D — Export and verify
1. Tap the resolution label near Export if present.
2. Review only the resolution and frame-rate choices actually offered by this device/app.
3. Choose a setting supported by the source and the delivery brief. Upscaling low-resolution footage does not restore missing detail.
4. Export to the device.
5. Open the exported video in the device's gallery/player.
6. Check duration, framing, text, audio, sync and playback.
7. Return to CapCut and verify the editable draft remains available.
8. Back up the draft/media using supported app/device options; do not assume an exported MP4 contains editable tracks.

## Worked assignment
Create a 30–45 second vertical tutorial using 5–7 self-recorded shots, one voice-over, one title and corrected captions. Keep the message understandable with sound muted and with audio enabled.

## Troubleshooting
- Export resolution option missing: check app version, source resolution, device capability and regional availability; accept the highest suitable available setting.
- Export fails: check storage, simplify heavy effects, close background apps and retry a short test.
- Captions wrong: proofread against original speech; auto-captioning is not authoritative.
- Project missing: check account, local/cloud project view and device storage; use the app's current Help Center instructions.
- Text hidden: inspect layer order, opacity, size and placement.
- Reframing cuts off subject: adjust each clip separately instead of relying on a global center crop.

## Knowledge check
1. Does every phone support 4K export?
2. Is an exported MP4 the same as an editable draft?
3. Why proofread auto captions?
4. Why check storage before export?
5. Why reframe every vertical shot?

### Answer key
1. No; device, source, region and app version affect available choices.
2. No; the MP4 is rendered output, while the draft holds editable project structure.
3. Speech recognition can mishear words, names and numbers.
4. Rendering needs temporary and output storage.
5. Subjects and important information may not remain centered or visible.

This is not a universal minimum for all editing features. Verify the current help article and the app's visible export menu on the learner's device.
