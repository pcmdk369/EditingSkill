# CT-01 Software Lab 02 — Adobe Premiere Pro: Sequence, Edit, Audio and Export

**Track:** Desktop NLE  
**Reference baseline:** Current Premiere desktop Help pages checked 16 November 2026. Adobe updates the interface and export workflow; use the Help page matching the installed release.  
**Practice time:** 2–3 hours  
**Prerequisites:** CT-01 Lessons 01–08  
**Assets:** 5–8 rights-cleared video clips, voice recording, licensed/owned music and one still.

## Outcomes
Set up a Premiere project, create a sequence, organize assets, edit a short story, add titles/audio and export a verified file.

## Version-aware interface note
Adobe's current documentation describes sequence creation through the Project panel and New Item workflow, and export through File > Export > Media or Ctrl+M (Windows)/Command+M (macOS). Panels, labels and presets may vary by release and workspace. If the menu differs, use Premiere's command search or current in-app Help rather than assuming an old tutorial is exact.

## Key terms
- Project panel: organizes imported assets and sequences.
- Sequence: timeline with its own video/audio and format settings.
- Program Monitor: displays sequence output.
- Source Monitor: previews source media.
- Track targeting: determines which tracks receive certain edit operations.
- Export mode/dialog: configures output file, format, preset and destination.

## Lab A — Create project and sequence
1. Create a project folder with Project, Media, Audio, Graphics, Exports and Documentation subfolders.
2. Launch Premiere and create a project inside the Project folder.
3. Import the practice media into the Project panel.
4. Create bins for Video, Audio, Stills and Sequences.
5. Inspect source frame rates and dimensions.
6. Create a sequence by dragging a representative clip to the New Item icon, or use the sequence creation command and set the confirmed delivery properties manually.
7. Verify sequence dimensions and frame rate; document the choice.
8. Save, close and reopen the project to confirm media links.

## Lab B — Edit and organize
1. Create a rough cut with a clear opening, development and payoff.
2. Use Source Monitor to mark useful source ranges where practical.
3. Place clips on the timeline and trim using the intended edit operation.
4. Before ripple edits, inspect track targeting and sync-lock behavior; verify downstream clips.
5. Put dialogue, ambience/effects and music on separate tracks.
6. Build at least one J-cut and one L-cut by adjusting audio and picture edit points independently.
7. Add a simple title or lower third and check spelling, contrast and safe placement.
8. Save a new version before finishing.

## Lab C — Sound and visual finish
1. Set dialogue as the intelligibility reference.
2. Adjust clip volume before adding heavy processing.
3. Fade audio edits and listen for clicks.
4. Lower or automate music under speech.
5. Use Lumetri Color or the color controls available in the installed version to correct exposure/white balance and match shots.
6. Keep creative looks subtle and verify any LUT's input assumptions.
7. Review the sequence from beginning to end.

## Lab D — Export
1. Select the intended sequence in the Timeline panel.
2. Open File > Export > Media, or use Ctrl+M/Command+M as documented by Adobe.
3. Set filename and destination.
4. Choose a format and preset that satisfy the delivery specification. Adobe currently documents H.264 as a common online delivery option and Match Source – Adaptive High Bitrate as a convenient starting preset—not a substitute for checking the actual requirements.
5. Review dimensions, frame rate, audio and duration in export settings.
6. Export directly or send to Adobe Media Encoder if a queued workflow is appropriate.
7. Play the output independently and inspect the full programme.
8. Record actual file properties and any deviations from the brief.

## Worked assignment
Create a 60-second interview excerpt with B-roll, one J-cut, one L-cut, a lower third and balanced music. Deliver a review MP4 plus the editable project folder.

## Troubleshooting
- Wrong sequence properties: inspect sequence settings; create a correct sequence before extensive work if needed.
- Ripple edit shifts unrelated clips: inspect track targeting, sync lock and linked selection.
- Export uses wrong range: confirm sequence selection and source/range controls.
- Export too large: choose an appropriate delivery preset/bitrate from the brief; do not reduce quality blindly.
- Missing media on another machine: use the project's media collection/packaging workflow where available and verify the recipient can relink.
- Encoder queue stalls: check disk space, source media availability, effect compatibility and output path.

## Knowledge check
1. What distinguishes a project from a sequence?
2. How can a clip create a sequence quickly?
3. Which shortcut opens Export Media on Windows and macOS?
4. Why is a preset only a starting point?
5. Why keep dialogue and music on separate tracks?

### Answer key
1. A project contains assets and sequences; a sequence is one editable timeline with its own settings.
2. Drag a clip to the New Item icon (or use sequence creation).
3. Ctrl+M on Windows; Command+M on macOS.
4. Delivery requirements and source properties may differ.
5. Independent balancing, fades and automation are easier.
