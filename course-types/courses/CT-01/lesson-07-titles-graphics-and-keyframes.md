# CT-01 — Intermediate: Titles, Graphics and Keyframe Animation

**Course:** Video Editing  
**Pathway stage:** Intermediate

## Learning outcomes
Design readable titles; establish visual hierarchy; animate position, scale and opacity with keyframes; use easing; maintain safe placement and consistent graphic style.

## Prerequisites
Lessons 01–06; a sequence with a clear opening and ending.

## Key definitions
- Typography: visual design of written language.
- Hierarchy: visual ordering that tells viewers what to notice first.
- Lower third: graphic identifying a speaker or providing contextual information, commonly placed in the lower portion of the frame.
- Keyframe: stored parameter value at a specific time.
- Interpolation: method used to calculate values between keyframes.
- Linear motion: constant parameter change over time.
- Ease-in/ease-out: gradual acceleration or deceleration near a keyframe.
- Safe area: region kept clear of edges and interface overlays to protect important content.

## Why it matters
Titles can orient the viewer, identify people and make information accessible. Poor typography or excessive animation competes with the story.

## Theory
Use contrast, hierarchy and restraint. A title should be readable at the smallest expected screen size. Keep typefaces and colors consistent. Keyframes animate a property over time; interpolation determines how it moves between values. Linear movement can feel mechanical; easing can make motion feel more natural, but should not create unnecessary bounce.

## Tools and alternatives
Use built-in title generators, graphic layers, vector graphics or a separate design application. Static titles are preferable when animation adds no value.

## Procedure
1. Identify the title's function: opening, speaker ID, location, chapter, callout or end card.
2. Write the shortest accurate text.
3. Choose a typeface with clear letterforms and adequate language support.
4. Establish hierarchy through size, weight, spacing and contrast.
5. Place text away from edges and likely platform interface overlays.
6. Preview on a phone-sized display or reduced viewer.
7. For animation, set a starting keyframe for opacity or position.
8. Move the playhead to the intended end time and set the final value.
9. Choose interpolation and adjust easing to suit the content.
10. Check for clipped text, flicker, unreadable speed and inconsistent styling.
11. Review titles over bright and dark footage; add a restrained backing or shadow only if needed.
12. Export a short test and inspect it on the intended display size.

## Worked example
A speaker lower third appears after the audience has seen the speaker. It fades in while moving a small distance upward, holds long enough to read, then fades out. Name and role use separate hierarchy levels. The text is checked against the actual speaker spelling.

## Dry run
Animate opacity from 0% to 100% over 12 frames, hold, then return to 0% over 12 frames. Compare linear and eased interpolation. Use the values as an exercise, not a universal design rule.

## Guided exercise
Create an opening title, one lower third and an end card using a two-font maximum system and consistent spacing.

## Independent assignment
Create a 45-second information video with three graphic elements. Submit a style sheet listing typefaces, sizes, colors and placement rules, plus a short note on animation timing.

## Common errors and recovery
- Text too close to frame edge: move it inward and check platform overlays.
- Low contrast: simplify the background or add a restrained backing.
- Animation too fast: lengthen the hold and review at phone size.
- Keyframes cause unexpected movement: inspect parameter values and interpolation at each keyframe.
- Inconsistent font styles: use a small documented type system.

## Knowledge check
1. What does hierarchy communicate?
2. What is a keyframe?
3. How does easing differ from linear interpolation?
4. Why preview at phone size?
5. Name three functions a title may serve.

## Answer key
1. The order in which information should be noticed.
2. A parameter value stored at a particular time.
3. Easing changes speed gradually; linear interpolation changes at a constant rate.
4. To confirm readability and safe placement on the actual viewing device.
5. Opening, speaker identification, location, chapter, callout or end card.
