# CT-01 Lesson 01 — Editing Workflow and Project Setup

- Stage: Foundation
- Practice time: 60–90 minutes
- Prerequisites: None
- Tools: Any non-linear video editor (NLE), file manager and media player
- Practice assets: 3–5 self-recorded or openly licensed clips, one still image and one audio recording

## Learning outcomes
Explain the editing workflow; distinguish source media, project files, timelines and exports; organize a portable project; choose sequence settings from a delivery brief; preserve original assets.

## Key definitions
- Editing: selecting and arranging media to communicate a story or message.
- Post-production: editing, sound, color, titles, captions, export and delivery after capture.
- NLE: software that arranges media without modifying the original source files.
- Source media: original video, audio, graphics and still images.
- Project file: edit instructions and references to media, not necessarily the media itself.
- Timeline: ordered clips arranged over time.
- Sequence: a timeline with defined dimensions and playback settings.
- Export/render: creation of a playable output file from the project.
- Frame rate: number of frames displayed per second (fps).
- Aspect ratio: proportional relationship between width and height, such as 16:9 or 9:16.

## Why this matters
A good edit can fail when media goes missing, sequence settings are unsuitable or the project cannot be reopened. Reliable setup makes creative work repeatable and revisions possible.

## Theory
Editing has creative and technical dimensions. Creative choices control information, emotion and pace. Technical choices determine whether the media can be decoded, edited and delivered reliably.

Use this pipeline: brief → rights check → copy and verify media → organize → inspect → create project and sequence → assemble → refine → sound/color/captions → export → inspect → deliver and archive.

A project may reference source files by their file paths. Moving or renaming folders after import can break those links. Keep the project folder stable.

Common aspect ratios: 16:9 landscape; 9:16 vertical; 1:1 square; 4:3 traditional display. Resolution is pixel dimensions, not a guarantee of image quality. Focus, exposure, compression and source quality also matter.

Choose sequence settings from the delivery brief. If no brief exists, match the dominant source footage where practical and document the decision. Avoid unnecessary frame-rate conversion because it can create repeated, blended or dropped frames.

## Tools and alternatives
Any NLE such as DaVinci Resolve, Premiere Pro, Final Cut Pro, CapCut or VN. Menu names vary. Use the operating system file manager to organize media and a trusted media-information tool to inspect properties.

## Procedure
1. Write the project purpose and intended audience.
2. Record platform, duration, orientation, resolution, frame rate and format. Mark unknowns as unconfirmed.
3. Create a project root folder named ProjectName_Date.
4. Create folders: Project, Source_Video, Source_Audio, Graphics, Exports, Review and Documentation.
5. Copy assets into the appropriate source folders; keep a separate backup.
6. Inspect media for duration, dimensions, frame rate, orientation, codec and audio presence.
7. Create and save a new NLE project inside the Project folder.
8. Create a sequence from confirmed delivery settings; document any assumption.
9. Close and reopen the project to confirm media remains online.
10. Record project location and sequence settings in a brief.

## Worked example
Brief: a 45-second introduction to a handmade craft process, landscape web delivery. Source footage is 1920×1080 at 25 fps. A 1920×1080, 25 fps sequence is a sensible starting point unless the delivery specification requires otherwise.

## Dry run
Expected folder structure:
- ProjectName_Date/
  - Project/
  - Source_Video/
  - Source_Audio/
  - Graphics/
  - Exports/
  - Review/
  - Documentation/

Expected result: saved project, correctly configured empty sequence, organized media and documented delivery target.

## Guided practice
Use three original clips. Create the folder structure, inspect the clips, create a sequence and reopen the project. Record any missing or unusual media properties.

## Independent assignment
Prepare a project for a 60-second story. Submit the brief, folder tree, source inventory, sequence settings and a screenshot showing media online.

## Common errors and recovery
- Project saved in a temporary folder: move it before editing and reopen to test links.
- Source folders moved after import: relink to the stable folder and stop renaming it.
- Wrong orientation: create a correctly configured sequence and migrate the edit only after checking application behavior.
- Frame rate guessed: inspect source properties and delivery requirements.
- No backup: stop and create a verified copy before editing.

## Knowledge check
1. How does a project file differ from an export?
2. Why should source folders remain stable?
3. What should determine sequence settings?
4. Does 4K resolution alone guarantee quality?
5. Why reopen the project after setup?

## Answer key
1. The project contains edit instructions/references; the export is the rendered playable file.
2. The project may link to media using file paths.
3. The delivery brief, informed by source properties.
4. No; focus, exposure, compression and source quality also matter.
5. To verify that the project and media links work.

## Assessment rubric — 20 points
Brief and delivery target 4; folder organization 4; source inventory and backup 4; sequence-setting reasoning 4; reopen test and documentation 4. Pass: 16/20, with no missing source media.

## Quality-control checklist
- [ ] Project saved in intended folder.
- [ ] Originals preserved and backup created.
- [ ] Source media readable and organized.
- [ ] Sequence settings documented.
- [ ] Project reopens with media online.
- [ ] Unknown requirements are clearly marked.

## Further study
Study codecs, containers, timecode, frame rates and storage. Verify software-specific menu names against the installed application version.
