# CT-21 Capstone — Virtual Studio Keying Package

- Level: Master / Professional Practice
- Estimated time: 10–16 hours
- Status: Brief authored; learner execution and review not evidenced

## Brief
Plan and produce a keyed presenter shot for a virtual studio. Deliver clean matte, foreground, final composite and reusable capture guidance.

## Deliverables
- production brief and shot plan;
- lighting/wardrobe/camera guide;
- original plate and camera metadata;
- key/matte and edge-refinement project;
- final composite and requested foreground/alpha;
- background integration notes;
- AI/provenance note if applicable;
- QC report, project manifest and reflection.

## Mandatory gates
Use authorized talent/footage. Preserve source plates. Verify alpha convention and full-motion quality.

## Rubric — 100 points
| Criterion | Points |
|---|---:|
| Production/capture planning | 15 |
| Matte quality | 20 |
| Edge/spill/hair detail | 15 |
| Background integration | 20 |
| Temporal consistency | 10 |
| Technical export/alpha | 10 |
| Rights and handoff | 10 |

Pass 80/100. Rights, matte integrity and complete playback are mandatory.

## Review
Reviewer checks capture metadata, matte, edge quality, full-motion composite, alpha export and project dependencies. Actual learner evidence is required for validation.
