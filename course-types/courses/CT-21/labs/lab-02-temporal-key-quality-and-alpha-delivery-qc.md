# CT-21 Professional Lab 02 — Temporal Key Quality and Alpha Delivery QC

- Course: CT-21 — Green Screen & Chroma Key
- Level: Advanced / Professional
- Estimated time: 4–5 hours
- Environment: NLE/compositor with keying and alpha tools; review display and export inspector
- Lab status: Authored procedure; capture hardware and keyer behavior are not tested here

## Brief
Create a 10–20 second green-screen composite featuring hair or semi-transparent detail and subject movement. Deliver the composite, foreground with alpha and matte diagnostic views where supported.

## Procedure
1. Inventory source footage and record camera, codec, frame rate, shutter, resolution and lighting notes.
2. Preserve original footage and create a working copy.
3. Inspect screen exposure, wrinkles, shadows, spill and subject motion.
4. Build an initial key using representative clean screen samples.
5. Refine matte using core/edge separation, masks and garbage mattes.
6. Inspect hair, motion blur, translucent fabric and fine edges frame by frame.
7. Apply despill conservatively; compare skin and wardrobe to source.
8. Match foreground and background exposure, white balance, perspective and depth.
9. Add contact shadow or environmental integration only where justified by the scene.
10. Review the entire sequence for edge chatter, flicker, matte holes and tracking drift.
11. Export composite and alpha version using the specified alpha convention and codec.
12. Reopen exports and composite alpha over light, dark and saturated backgrounds.
13. Compare output dimensions, frame rate, color and alpha metadata to the brief.
14. Record unresolved limitations and package project/media.

## Validation
| Test | Method | Pass condition |
|---|---|---|
| Matte | Inspect diagnostic view | Subject separated without holes |
| Edge | Frame-by-frame review | No distracting chatter |
| Spill | Compare source and keyed subject | Natural subject color |
| Integration | Review shadow/perspective | Foreground belongs in scene |
| Alpha | Composite over varied backgrounds | No fringe or inversion |
| Temporal | Full playback | Stable key throughout |
| Export | Metadata and playback | Meets specification |

## Troubleshooting
- Green edge: refine despill and matte edge.
- Dark halo: inspect premultiplication and edge color.
- Hair flicker: adjust temporal settings carefully and inspect frame-by-frame.
- Shadow mismatch: match direction and softness to background lighting.
- Alpha inversion: verify channel interpretation and export setting.

## Deliverables
Source inventory, key project, composite, alpha foreground, matte diagnostics, edge QC contact sheet and export manifest.

## Assessment — 100 points
Matte quality 20; edge/hair 20; spill 10; integration 15; temporal stability 15; alpha/export 10; documentation 10. Pass 80/100.

## Completion checklist
- [ ] Source capture settings documented.
- [ ] Matte and edge checked across motion.
- [ ] Despill preserves subject color.
- [ ] Composite perspective/light coherent.
- [ ] Alpha convention verified.
- [ ] Export metadata and full playback checked.
- [ ] QC and handoff complete.
