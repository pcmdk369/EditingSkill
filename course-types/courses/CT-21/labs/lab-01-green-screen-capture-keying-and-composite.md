# CT-21 Professional Lab 01 — Green Screen Capture, Keying and Composite

- Level: Advanced / Professional
- Estimated time: 5–7 hours
- Environment: Camera, screen lighting, compositor; record OS/app/version and camera settings
- Lab status: Authored procedure; not executed in this session

## Brief
Capture or use an authorized 5–10 second green-screen clip and composite the subject into a matching environment. Deliver matte, foreground and final composite.

## Prerequisites
Complete CT-21 Lessons 01–04. Record camera/lens, frame rate, resolution, shutter/exposure and color settings. Use authorized talent/footage.

## Procedure
1. Plan wardrobe, framing and key color.
2. Light screen evenly and separately from subject.
3. Separate subject from screen and control spill.
4. Record test clip and inspect motion/edges.
5. Preserve source plate and metadata.
6. Create garbage and holdout mattes.
7. Generate chroma key and inspect alpha.
8. Refine hair/transparent edges and spill.
9. Match subject scale, light and perspective to background.
10. Add contact/cast shadow where appropriate.
11. Review on contrasting backgrounds and full motion.
12. Export final composite and matte/foreground as specified.
13. Package project, plate, background, camera notes and manifest.

## Expected artifacts
Source plate, camera/lighting diagram, matte, foreground, final composite, project and QC report.

## Validation
| Test | Method | Expected result |
|---|---|---|
| Screen | Inspect source plate | Even illumination |
| Matte | Alpha view | Solid subject, clean transparency |
| Edge | Light/dark background | No major halo/chatter |
| Spill | Subject color check | Natural skin/wardrobe |
| Integration | Full composite playback | Scale/light/perspective consistent |
| Export | Metadata and alpha test | Matches brief |
| Handoff | Reopen package | Dependencies available |

## Troubleshooting
Uneven screen: improve lighting or use multiple keys. Hair holes: refine matte/holdout. Spill: isolate edge correction. Floating subject: match contact shadow. Alpha fringe: verify convention.

## Assessment — 100 points
Capture quality 15; matte 20; edge/spill 15; integration 20; temporal QC 10; technical export 10; rights/handoff 10. Pass 80/100.

## Handoff
Submit source, matte, foreground, composite, lighting guide, camera metadata, project and QC report.
