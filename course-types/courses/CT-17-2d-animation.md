# 2D Animation

**Course ID:** CT-17  
**Pathway:** Foundation → Beginner → Intermediate → Advanced → Expert → Master → AI & Automation → Professional Practice

## Purpose and outcomes
Develop 2D animation skills from frame-based fundamentals through pose-to-pose animation, character mechanics, effects/compositing, production cleanup, art direction, responsible AI assistance and professional delivery.

Learners will plan animation, control timing/spacing, build readable motion, maintain model consistency, manage production layers and deliver complete source projects.

## Software track
Use a current 2D animation application with timeline, layers and image-sequence export. Record frame size, frame rate, color and alpha settings. Verify export procedures in the selected application's official documentation.

## Completion requirements
Pass the 50-point assessment, submit lab and capstone, meet rights/model consistency gates and provide editable source plus validated export. Suggested capstone pass: 80/100. Independent review and learner execution evidence remain required.
