# CT-26 Capstone — Consent-First Localized Voice Package

- Level: Master / Professional Practice
- Estimated time: 10–14 hours
- Status: Brief authored; learner execution and independent review not evidenced

## Brief
Create a localized 60–90 second video/audio segment in one target language using an authorized human speaker or a properly licensed synthetic voice that does not imitate an unauthorized real person. Preserve source meaning and provide a reproducible handoff.

## Required deliverables
- source media inventory and rights record;
- source transcript with timecodes;
- reviewed target-language script and glossary;
- pronunciation/timing guide;
- voice performer release or synthetic voice license/consent;
- provider/model/version and provenance record if AI is used;
- aligned voice track and final mix;
- captions/subtitles as specified;
- synthetic-media disclosure plan where required;
- QC report and version log;
- archive/retention plan and 500-word reflection.

## Mandatory gates
No unauthorized voice cloning, deceptive impersonation, fabricated endorsement, unreviewed translation or external processing without permission. Delivery permission and portfolio permission are separate.

## Rubric — 100 points
Source and task planning 10; transcript/translation accuracy 20; voice performance 15; timing/sync 15; consent/rights/privacy 20; disclosure/provenance 10; QC/handoff 10. Pass 80/100. Rights and consent failures are critical.

## Review protocol
Reviewer checks target script against source, verifies voice permissions and provider scope, listens to the full output, inspects timing and audio properties, and records defects. Course validation requires actual project evidence; this brief alone does not validate a learner project.
