# CT-07 Professional Lab 01 — Layered Photo Correction and Delivery

- Level: Intermediate / Professional
- Estimated time: 4–6 hours
- Environment: Raster editor and optional RAW processor; record OS/app/version and color profile
- Lab status: Authored procedure; not executed in this session

## 1. Brief
Correct and prepare a five-image set for web delivery. Preserve originals, use non-destructive layers, maintain consistent color, and deliver editable sources plus exports.

## 2. Prerequisites and rights
Complete CT-07 Lessons 01–04. Use learner-created or licensed images. Confirm model/property releases if applicable. Record source dimensions and intended destination requirements.

## 3. Folder structure
```text
ct07-photo-lab/
  originals/
  working/
  projects/
  exports/web/
  references/
  rights/
  qc/
  delivery/
```

## 4. Procedure
1. Inventory all five originals and back them up.
2. Record dimensions, file type, profile and metadata where available.
3. Identify one reference image for the set.
4. Correct exposure and white balance on a working copy.
5. Use layers and masks for local adjustments.
6. Remove only permitted distractions; document material changes.
7. Match color and contrast across the set without forcing identical treatment.
8. Inspect edges, noise, sharpening and artifacts at 100% and intended output size.
9. Export proof files using destination requirements.
10. Inspect dimensions, profile, compression and appearance on another display if possible.
11. Create final exports and manifest.
12. Package editable project and linked assets.

## 5. Expected artifacts
Five edited images, layered project, source inventory, adjustment notes, rights log, export manifest and QC report.

## 6. Validation
| Test | Method | Expected result |
|---|---|---|
| Original preservation | Compare source folder | Originals unchanged |
| Dimensions/profile | Metadata inspection | Match web specification |
| Color consistency | Compare reference set | Coherent, no unexplained cast |
| Retouch integrity | Inspect at 100% | No obvious artifacts or misleading alteration |
| Export | Open every file | Files display correctly |
| Handoff | Open project from package | Dependencies available |

## 7. Troubleshooting
Banding: inspect bit depth and adjustment strength. Color shift: verify profiles and export conversion. Halo: refine mask/edge. Compression artifacts: adjust export quality or format. Missing font/plugin: document dependency or rasterize only when contractually appropriate.

## 8. Assessment — 100 points
Source preservation 10; correction quality 20; masks/layers 15; consistency 15; retouch integrity 10; export compliance 15; rights/metadata 5; handoff 10. Pass 80/100; source integrity and rights are mandatory gates.

## 9. Handoff
Submit original inventory, editable files, five exports, manifest, rights log and QC notes.
