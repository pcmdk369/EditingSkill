# CT-17 Professional Lab 01 — Bouncing Ball and Character Walk Cycle

- Level: Intermediate / Professional
- Estimated time: 4–6 hours
- Environment: 2D animation application; record OS/app/version, canvas and frame rate
- Lab status: Authored procedure; not executed in this session

## Brief
Create a 3-second bouncing-ball animation and a looping character walk cycle. Demonstrate timing, spacing, key poses, breakdowns and consistent volume.

## Prerequisites
Complete CT-17 Lessons 01–03. Use original drawings or authorized character designs.

## Procedure
1. Create project with specified canvas and frame rate.
2. Draw a timing chart for the ball.
3. Animate key positions and impact pose.
4. Add squash/stretch only where appropriate to material and style.
5. Inspect arcs and spacing.
6. Create character model sheet.
7. Draw contact, down, passing and up poses.
8. Add breakdowns and in-betweens.
9. Check foot planting, weight shift and silhouette.
10. Preview at normal playback speed.
11. Correct volume drift and timing.
12. Export preview and preserve editable project.

## Expected artifacts
Bouncing-ball animation, walk-cycle loop, timing charts, model sheet and editable project.

## Validation
| Test | Method | Expected result |
|---|---|---|
| Timing | Frame count/playback | Action duration matches brief |
| Spacing | Frame-by-frame review | Clear acceleration/deceleration |
| Arc | Onion-skin/trajectory | Smooth readable path |
| Volume | Compare adjacent frames | Consistent size/form |
| Walk cycle | Loop playback | Foot contact and weight shift clear |
| Export | Full playback | No missing frames |

## Troubleshooting
Mechanical bounce: revise spacing. Foot slide: correct contact frames. Volume drift: compare model guide. Jerky loop: align cycle endpoints and timing.

## Assessment — 100 points
Timing/spacing 25; key poses/breakdowns 20; arcs and volume 15; walk mechanics 20; project organization 10; export/QC 10. Pass 80/100.

## Handoff
Submit editable project, preview, timing charts, model sheet and QC notes.
