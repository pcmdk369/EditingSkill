# CT-17 Professional Lab 02 — Animation Timing, Cleanup and Frame-Sequence QC

- Course: CT-17 — 2D Animation
- Level: Advanced / Professional
- Estimated time: 4–6 hours
- Environment: 2D animation application, image-sequence viewer and video encoder
- Lab status: Authored procedure; not executed in a specific application

## Brief
Create a 5–8 second original action animation with a clear anticipation, action, follow-through and settle. Deliver an editable project, image sequence with alpha if required, and a review movie.

## Procedure
1. Define frame rate, canvas, color and delivery format from the brief.
2. Create a timing chart and key poses before drawing all in-betweens.
3. Block silhouette, staging and spacing; review at intended playback speed.
4. Add breakdowns, arcs, overlap and secondary action where motivated.
5. Check weight and contact against a consistent ground plane.
6. Clean linework and maintain model proportions across frames.
7. Review onion-skin frames for accidental jitter and shape drift.
8. Add color/cleanup layers and verify layer order.
9. Export an image sequence using consistent frame numbering and alpha settings.
10. Inspect first, middle and last frames, missing numbers, alpha edges and color.
11. Encode a review movie with the specified frame rate; check for duplicate/dropped frames.
12. Reopen project and verify all linked assets are present.
13. Record application/version, frame range, frame rate, export settings and QC results.

## Technical concepts
- Timing: number of frames allocated to an action.
- Spacing: distance moved between successive frames.
- Exposure: how long a drawing is held.
- Arc: path of a moving point.
- Anticipation: preparatory action that clarifies the main movement.
- Follow-through: continued movement after the main action.
- Image sequence: individually numbered frames that form an animation.

## Validation
| Test | Method | Pass condition |
|---|---|---|
| Motion readability | Playback at target speed | Action clear and intentional |
| Contact/weight | Inspect key poses | No unintended sliding |
| Model consistency | Compare key frames | Proportions stable |
| Sequence integrity | Check numbering | No missing/duplicate frames |
| Alpha | Composite over contrasting backgrounds | Edges correct |
| Frame rate | Inspect encoded file | Matches brief |
| Project portability | Reopen package | Dependencies available |

## Troubleshooting
- Jitter: inspect spacing and line stability.
- Floaty motion: strengthen contact and timing.
- Broken alpha: inspect premultiplication and export setting.
- Missing frames: regenerate sequence range and validate numbering.
- Choppy encode: verify frame rate and frame sequence order.

## Deliverables
Timing chart, editable project, numbered image sequence, review movie, export settings, QC report and manifest.

## Assessment — 100 points
Timing/spacing 20; posing/staging 15; mechanics 15; cleanup/model consistency 15; sequence/alpha integrity 15; technical export 10; documentation 10. Pass 80/100.
