# CT-17 Lesson 01 — Animation Principles, Timing, Spacing and Project Setup

- Course: CT-17 — 2D Animation
- Level: Foundation / Beginner
- Estimated time: 120–180 minutes
- Prerequisites: Basic drawing and frame-based media understanding
- Tools/environment: 2D animation application or drawing editor with timeline; record OS/app/version, canvas and frame rate
- Version/review date: Tool-neutral; delivery specs depend on client/platform

## Learning outcomes
Understand frame-based animation, timing and spacing, and organize a 2D project with clear output specifications.

## Key definitions
- **Frame:** One image in an animation sequence.
- **Timing:** Number of frames assigned to an action.
- **Spacing:** Distance an object/character moves between frames.
- **Key pose:** Important pose defining an action.
- **Breakdown:** Pose defining how motion moves between key poses.
- **Onion skin:** Display of neighboring frames to guide drawing.
- **Animatic:** Timed storyboard used to test sequence and pacing.
- **Cleanup:** Refining rough drawings into final consistent line work.

## Purpose and theory
Animation creates the illusion of movement through changing images over time. Timing is the number of frames used for an action; spacing is the distance an object travels between frames. Principles such as anticipation, follow-through, arcs and squash/stretch support clarity and appeal but should respect the subject and style.

## Tools, requirements and alternatives
Use a current 2D animation or drawing application with timeline/layer support. Record canvas size, frame rate, color settings and application version. Preserve source drawings and use original/licensed assets.

## Procedure
1. Define audience, style and deliverable. 2. Set frame size, frame rate and duration. 3. Create a storyboard and animatic. 4. Organize scenes, layers and assets. 5. Plan key poses and timing. 6. Create a simple bouncing-ball test. 7. Review arcs and spacing. 8. Save source project and render a preview.

## Worked example
A ball accelerates as it falls, compresses on impact and slows as it rises. Frame spacing communicates speed.

## Dry run
Ball moves equal distance every frame, appearing mechanical. Adjust spacing to show acceleration and deceleration.

## Guided practice
Create a 3-second bouncing-ball animation with clear timing chart.

## Independent assignment
Apply the technique to a second action or short sequence. Submit source project, preview, timing notes and QC evidence.

## Common errors and recovery
| Symptom | Likely cause | Diagnosis | Recovery |
|---|---|---|---|
| Submit project, timing chart, preview and settings. | Animation issue | Inspect adjacent frames and project settings | Correct and preview again |

## Knowledge check
1. How do timing and spacing differ?
2. Why use key poses and breakdowns?
3. What causes foot sliding in a walk cycle?
4. Why test an animatic before cleanup?
5. What should be checked in an AI-assisted sequence?

## Answer guidance
1. Timing is duration; spacing is movement distance between frames.
2. They establish readable action and control motion before in-betweening.
3. Contact frames and ground relationship are inconsistent.
4. It catches story/staging/pacing issues before expensive production.
5. Character consistency, temporal flicker, anatomy, rights and provenance.

## Quality-control checklist
- [ ] Canvas and frame rate match brief.
- [ ] Key poses and motion arcs are readable.
- [ ] Character volume/model consistency maintained.
- [ ] Effects/camera do not obscure action.
- [ ] AI output checked frame-by-frame where used.
- [ ] No missing frames or alpha artifacts.
- [ ] Project and source assets archived.
