# CT-30 — Professional Post-Production & Finishing Assessment

**Total:** 50 points | **Suggested time:** 45–60 minutes

## Part A — Multiple choice (10 × 2 = 20)
1. A master is: A. Approved high-quality source deliverable B. Any proxy C. Temporary cache D. Thumbnail
2. Conform connects: A. Approved edit to intended source/finishing media B. Social account C. Email D. Playlist
3. Relinking should use: A. Filename guess only B. Verified source identity and metadata C. Random file D. New media
4. A change request should record: A. Request and affected versions B. Only color C. Only date D. No approval
5. QC must inspect: A. Exported file B. Timeline only C. Filename only D. Thumbnail only
6. A checksum helps verify: A. File integrity B. Color taste C. Editorial quality D. Loudness
7. Copying to two drives proves archive restore. A. True B. False
8. A missing font/plugin should be: A. Ignored B. Documented and resolved/fallback agreed C. Deleted silently D. Hidden
9. AI QC output is: A. Suggestion needing review B. Final legal approval C. Proof of rights D. Guaranteed
10. Portfolio permission is automatic. A. True B. False

## Part C — Applied case (15)
16. An online conform has the right filename but the wrong camera take. Explain how to detect and correct it safely. (8)
17. A delivery package has checksums but the project cannot reopen because dependencies are missing. Explain the corrective process. (7)

## Answer key
1 A; 2 A; 3 B; 4 A; 5 A; 6 A; 7 B; 8 B; 9 A; 10 B.
11. Master is the approved high-quality deliverable; derivatives are versions adapted for specific destinations. (3)
12. Source identity, frame rate/timecode, effects, transitions, sync, handles and titles. (3)
13. ID, severity, location/timecode, expected/actual, evidence, owner, status and retest. (3)
14. It proves that stored assets can actually be recovered and used. (3)
15. Approved exports, project/dependencies, manifest, rights/approvals, QC, checksums and restore notes. (3)
16. Compare source metadata/timecode, slate/visual content and shot logs; relink to verified source; preserve original and rerender proof. (8)
17. Reconcile dependency manifest, obtain permitted assets/plugins/fonts, relink, test on clean location, update package and rerun restore/QC. (7)

## Performance bands
45–50 exemplary; 40–44 competent; 35–39 developing; below 35 remediation. Missing source integrity or archive restore requires remediation.
