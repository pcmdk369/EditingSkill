# CT-30 Lesson — Offline/Online Conform and Media Relinking

- Course: CT-30 — Professional Post-Production & Finishing
- Level: Beginner / Intermediate
- Estimated time: 90–180 minutes
- Prerequisites: Video/audio editing fundamentals and organized project media
- Environment: Record NLE, finishing applications, OS, versions, codecs and storage environment
- Version/review: Use the exact client/platform specification and current tool documentation

## Learning outcomes
Explain the finishing concept, execute a repeatable procedure, diagnose failure and produce evidence for independent review.

## Definition and terminology
Offline editing may use proxies or lower-resolution media; online finishing reconnects approved edit decisions to full-quality sources and finishing assets.

## Purpose and professional relevance
Conform requires matching frame rate, timecode, source identity, handles, effects and sequence version.

## Tools and alternatives
Use an NLE, color/audio tools, metadata inspectors, checksum utility and secure storage. Exact interchange formats and application support vary; verify compatibility before conform. A spreadsheet or issue tracker can maintain change and QC records.

## Step-by-step procedure
Lock edit; export interchange/EDL/XML/AAF where supported; collect source manifest; relink by verified metadata; compare offline and online timelines; check missing media; inspect handles and effects; render short proof.

## Worked example
A proxy filename matches two camera files. Use source metadata/timecode and verify visually before relinking.

## Guided practice
Conform a short sequence from proxy to original media and report differences.

## Independent assignment
Apply the workflow to an authorized sample project. Submit source and output IDs, version history, settings, approvals, QC evidence and restore/handoff records as appropriate.

## Common errors and recovery
Relinking by filename alone; wrong frame rate; missing handles. Reconcile source IDs and test ranges.

## Assessment evidence
Submit conform report, relink log and comparison export.

## Knowledge check
1. Define the main finishing concept.
2. Why must finishing decisions be traceable to the approved version?
3. Which checks must be performed on the exported file?
4. What evidence demonstrates a reliable handoff?

## Answer guidance
1. Use the definition and distinguish master, derivative, conform and archive.
2. It prevents stale assets, unapproved changes and mismatched approvals.
3. Metadata, full playback, sync, audio, color, captions, graphics and integrity.
4. Manifest, dependencies, checksums, approvals, QC, receipt and restore test.

## Quality-control checklist
- [ ] Approved edit/version identified.
- [ ] Source and dependencies inventoried.
- [ ] Conform and specialist handoffs checked.
- [ ] Export tested against written specification.
- [ ] Defects recorded and retested.
- [ ] Rights and release approvals complete.
- [ ] Checksums/backup and restore evidence recorded.
- [ ] Receiving party can identify and use deliverables.

## Further study
Consult current official NLE interchange documentation, delivery platform specifications, preservation guidance and client technical standards.
