# CT-30 Capstone — Professional Master Delivery and Verified Archive

- Level: Master / Professional Practice
- Estimated time: 12–20 hours
- Status: Brief authored; execution and independent review not evidenced

## Brief
Take an approved edit through conform, finishing, mastering, QC and archive. Deliver one high-quality master, two destination derivatives and a reproducible project/archive package.

## Required deliverables
- approved brief and acceptance matrix;
- source/proxy inventory and conform report;
- project version/change log;
- color/audio/caption/graphics handoff records;
- master and two derivatives;
- metadata and full-playback QC reports;
- rights/approval records;
- asset manifest and checksums where available;
- archive package and clean-location restore report;
- 500–800 word reflection.

## Mandatory gates
No wrong source media, unapproved changes, missing rights, corrupt files or untested archive. Critical defects block release.

## Rubric — 100 points
Conform/source integrity 15; specialist finishing handoff 10; master quality 15; derivatives 10; technical QC 15; rights/approvals 10; archive/restore 15; documentation/reflection 10. Pass 80/100.

## Review protocol
Reviewer checks source mapping, opens project from package, inspects metadata, watches all exports, verifies defect closure and tests archive restore. This brief alone does not validate execution.
