# CT-29 Professional Lab 02 — Mobile Export, Backup and Device-Recovery Drill

- Level: Advanced / Professional
- Estimated time: 3–5 hours
- Environment: Smartphone, mobile editor, external/cloud storage and a second playback device
- Lab status: Authored procedure; no device/app-specific menus are tested

## Brief
Create a mobile edit, export multiple delivery variants, back up source/project assets and prove recovery after a simulated device-storage failure.

## Procedure
1. Record phone model, OS, editor version, storage and target export specs.
2. Inventory source media and preserve originals.
3. Build a project with organized assets and versioned saves.
4. Export a short proof and inspect metadata/playback on a second device.
5. Export the final variant and verify audio, captions, framing and duration.
6. Package the project and linked assets where the app supports it.
7. Back up to an authorized destination; verify file count and checksum where available.
8. Simulate loss of local working copy using a duplicate test folder, not the only original.
9. Restore the package to a clean location/device.
10. Reopen the project and verify fonts, music, transitions and media links.
11. Compare restored export with approved reference.
12. Document app limitations and any dependencies that cannot be transferred.

## Validation
Output matches spec; backup integrity verified; project restores; dependencies resolve or are disclosed; originals remain preserved.

## Deliverables
Final exports, project package, source manifest, backup record, restore test, QC report and limitations note.

## Assessment — 100 points
Export correctness 20; project organization 15; backup integrity 20; restore success 20; rights/privacy 10; QC/handoff 15. Pass 80/100.
