# CT-29 Professional Lab 01 — Smartphone-First Video Production and Delivery

- Level: Intermediate / Professional
- Estimated time: 4–6 hours
- Environment: Smartphone, mobile editor, headphones and backup storage
- Lab status: Authored procedure; device/app-specific menus must be verified by learner

## Brief
Create a 30–60 second vertical tutorial entirely on a smartphone. Deliver a review export, editable project where supported, captions and verified backup.

## Procedure
1. Record device model, OS, app versions and free storage.
2. Define audience, message, shot list, aspect ratio and destination requirements.
3. Check lens, lighting, microphone, battery and storage.
4. Record a test and inspect focus, exposure, audio and frame rate.
5. Record source clips; retain originals.
6. Transfer or organize media in a project folder and verify file counts.
7. Create selects and assemble a clear story.
8. Add titles/captions and proofread every word.
9. Balance dialogue/music and apply conservative color correction.
10. Review on the phone at actual size and listen with headphones.
11. Export a short proof and inspect metadata.
12. Export final, play from start to end and compare to the brief.
13. Back up project, sources and final output; verify a sample restore.
14. Create delivery manifest with file names, app version and limitations.

## Validation
Source backup exists; captions accurate; audio intelligible; safe framing; export metadata correct; full playback passes; archive restore succeeds.

## Assessment — 100 points
Planning/capture 15; story/edit 20; audio 15; captions/accessibility 15; visual quality 10; export 10; backup/handoff 15. Pass 80/100.
