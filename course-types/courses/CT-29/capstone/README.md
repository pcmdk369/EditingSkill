# CT-29 Capstone — Smartphone-First Creator Campaign

- Level: Master / Professional Practice
- Estimated time: 8–12 hours
- Status: Brief authored; learner execution and review not evidenced

## Brief
Produce a three-part short-form creator package using a smartphone-first workflow. Capture, edit, caption and export all content on mobile where feasible; document any desktop/cloud assistance.

## Required deliverables
- audience/message brief and shot list;
- source footage inventory and backup record;
- three distinct short-form edits;
- captions and thumbnail/cover assets;
- device/app/version and export settings;
- rights/consent register;
- AI/cloud privacy record if used;
- QC report and full-playback evidence;
- editable projects and linked assets where supported;
- archive manifest and 500-word reflection.

## Mandatory gates
Original media preserved; no unauthorized music/footage/likeness; captions reviewed; privacy terms checked before cloud upload; exports tested against current destination specifications.

## Rubric — 100 points
Planning/capture 10; story/edit craft 20; mobile workflow 15; audio/captions 15; visual consistency 10; rights/privacy 10; export/QC 10; archive/reflection 10. Pass 80/100.

## Review protocol
Reviewer inspects project/source organization, plays all exports, verifies rights/privacy notes, checks metadata and confirms backup restoration. This brief alone does not validate a completed project.
