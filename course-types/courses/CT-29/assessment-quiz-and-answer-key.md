# CT-29 — Mobile Editing & Creator Workflows Assessment

**Total:** 50 points | **Suggested time:** 45–60 minutes

## Part A — Multiple choice (10 × 2 = 20)
1. A test recording helps verify: A. Audio/framing/settings B. Follower count C. Copyright ownership D. Nothing
2. Original footage should be: A. Deleted after import B. Preserved and backed up C. Renamed randomly D. Compressed repeatedly
3. Cloud processing should be: A. Assumed private B. Checked in app/provider terms C. Ignored D. Always enabled
4. A mobile preview may differ from final export. A. True B. False
5. Storage planning should include: A. Source/cache/export space B. Only battery C. Only screen brightness D. None
6. Captions should be: A. Auto-published B. Proofread against source C. Hidden D. Added after upload only
7. Device heat can cause: A. Thermal throttling B. Rights approval C. Better resolution D. No effect
8. A client handoff may require: A. Project/dependencies B. Only a screenshot C. No manifest D. Password sharing
9. Platform specifications are: A. Permanent B. Subject to change C. Always identical D. Unnecessary
10. Portfolio use is automatic after delivery. A. True B. False

## Part B — Short answer (5 × 3 = 15)
11. Name three mobile capture checks before recording.
12. Why verify transferred files before deleting device copies?
13. Name two causes of mobile timeline stutter.
14. What should be checked in captions and audio?
15. What belongs in a mobile project handoff?

## Part C — Applied case (15)
16. A mobile app exports a video with clipped audio although preview sounds correct. Explain the diagnostic steps. (8)
17. A creator uses an AI auto-caption tool that processes media in the cloud. What should be checked before uploading a private interview? (7)

## Answer key
1 A; 2 B; 3 B; 4 A; 5 A; 6 B; 7 A; 8 A; 9 B; 10 B.
11. Lens, storage, battery, focus/exposure, frame rate, orientation, microphone/audio test. (3)
12. Prevent data loss and verify transfer completeness/integrity. (3)
13. Heavy effects, high-resolution codecs, low storage, thermal throttling, memory limits. (3)
14. Transcript accuracy, timing, intelligibility, clipping, music balance and sync. (3)
15. Final export, project/dependencies where supported, sources, app/device version, rights, QC and backup manifest. (3)
16. Inspect export settings, meter/exported file, check gain/limiter, compare preview vs render, render short proof, test alternate player and correct/re-export. (8)
17. Provider retention/training, privacy terms, processing location where relevant, access controls, consent, client authorization and permitted use. (7)

## Performance bands
45–50 exemplary; 40–44 competent; 35–39 developing; below 35 remediation. Unauthorized processing or loss of sole source files requires remediation.
