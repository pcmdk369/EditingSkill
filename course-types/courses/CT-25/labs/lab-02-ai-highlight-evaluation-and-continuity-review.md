# CT-25 Professional Lab 02 — AI Highlight Evaluation and Generative Continuity Review

- Level: Expert / Professional
- Estimated time: 5–7 hours
- Environment: Authorized source footage, AI-assisted editing tool, NLE and QC log
- Lab status: Authored procedure; no model/provider is tested or endorsed

## Brief
Evaluate AI-assisted scene detection, transcript search and highlight suggestions on a non-sensitive learner-created source video. Produce a human-reviewed short edit and assess any generative extension/upscaling separately.

## Procedure
1. Define task, audience, target duration and objective acceptance criteria.
2. Preserve original media and create a working copy.
3. Review provider terms, retention, training, commercial use and permissions.
4. Record provider/model/version, date, settings and input IDs.
5. Generate transcript/scene labels/highlight suggestions on an authorized sample.
6. Compare every selected moment with full source context and timecodes.
7. Log false positives, missed events, speaker errors and context omissions.
8. Build an edit from verified selections; retain source references.
9. If generative extension is proposed, check rights and create a separate labeled test.
10. Inspect motion continuity, objects, faces, text, shadows and frame-to-frame artifacts.
11. Reject any output that fabricates evidence or changes material meaning.
12. Export review cut, inspect metadata and watch full playback.
13. Document human corrections, approvals and limitations.

## Validation
Transcript accuracy; highlight context; source traceability; continuity; rights/privacy; export quality; provenance and human approval.

## Deliverables
AI task plan, provider assessment, model log, error analysis, source-linked selects, reviewed edit, continuity QC and provenance manifest.

## Assessment — 100 points
Task design 10; source/rights 15; highlight/context evaluation 20; continuity review 15; human corrections 15; technical QC 10; provenance/handoff 15. Pass 80/100.
