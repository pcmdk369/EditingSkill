# CT-28 Capstone — Live Session Highlight and Archive Package

- Level: Master / Professional Practice
- Estimated time: 10–16 hours
- Status: Brief authored; execution and independent review not evidenced

## Brief
Create an archive master and a three-clip highlight package from an authorized recorded live session. Preserve context, synchronize sources, document permissions and deliver accessible platform-ready files.

## Required deliverables
- event brief and permission register;
- source inventory and sync report;
- marker/highlight log with source timecodes;
- full archive master;
- three highlight edits;
- captions/transcript;
- guest/music/venue/sponsor rights and approvals;
- platform delivery matrix with verification date;
- QC report, version log and archive manifest;
- 500-word editorial reflection.

## Mandatory gates
No misleading quote edits, unauthorized music/likeness use, unreviewed private information or unsupported platform claims. Portfolio use requires separate permission.

## Rubric — 100 points
Source/sync 10; editorial integrity 20; highlight craft 15; audio/caption quality 15; rights/privacy 15; technical delivery 10; archive/handoff 10; reflection 5. Pass 80/100.

## Review protocol
Reviewer watches the full archive and each highlight, traces excerpts to source timecodes, checks permissions and captions, validates export metadata and confirms archive manifest. This brief alone is not execution evidence.
