# CT-28 — Live & Streaming Content Editing Assessment

**Total:** 50 points | **Suggested time:** 45–60 minutes

## Part A — Multiple choice (10 × 2 = 20)
1. A program recording always contains isolated camera sources. A. True B. False
2. Sync should be checked: A. Only at start B. At multiple points C. Only after export D. Never
3. A highlight should preserve: A. Context B. Only dramatic words C. Only reaction shots D. No source link
4. Live markers are useful for: A. Source-linked retrieval B. Changing codec C. Removing rights D. Creating consent
5. Platform specifications should be: A. Assumed from memory B. Verified currently C. Ignored D. Identical everywhere
6. Music in event footage may require: A. No rights B. Separate permission C. Only a filename D. A lower bitrate
7. AI highlight suggestions should be: A. Published directly B. Human-reviewed against full context C. Treated as facts D. Used to infer identity
8. Private information in a recording should be: A. Published B. Handled under privacy/incident policy C. Hidden only by cropping D. Ignored
9. Archive retention should be: A. Indefinite always B. Defined by policy/agreement C. Never recorded D. Public by default
10. Portfolio use automatically follows delivery. A. True B. False

## Part B — Short answer (5 × 3 = 15)
11. Distinguish program recording and ISO recording.
12. Name three fields in a highlight log.
13. Why can a highlight misrepresent an interview?
14. List three rights/permissions relevant to event footage.
15. What belongs in an archive manifest?

## Part C — Applied case (15)
16. An AI tool selects a guest quote but omits the next sentence that changes its meaning. Explain the editorial response and prevention step. (8)
17. A live event recording includes audience faces and background music; the client requests public social clips. Outline the release checks. (7)

## Answer key
1 B; 2 B; 3 A; 4 A; 5 B; 6 B; 7 B; 8 B; 9 B; 10 B.
11. Program is the switched/mixed output; ISO is an isolated source recording per camera/audio input. (3)
12. Source ID, in/out timecode, speaker, topic, context note, approval status. (3)
13. Removing qualifiers, responses or surrounding context changes meaning. (3)
14. Guest release, audience/location permission, music, sponsor/logo and footage rights. (3)
15. Files, versions, metadata, rights, approvals, retention and checksum/path where available. (3)
16. Return to full source, include qualifying context or reject clip, add context review to highlight approval checklist. (8)
17. Review releases/consent, music license, venue/organizer terms, privacy/face handling, sponsor/brand approvals and platform-specific requirements. (7)

## Performance bands
45–50 exemplary; 40–44 competent; 35–39 developing; below 35 remediation. Privacy or rights breach requires remediation.
