# Color Correction & Color Grading

**Course ID:** CT-12  
**Pathway:** Foundation → Beginner → Intermediate → Advanced → Expert → Master → AI & Automation → Professional Practice

## Purpose and outcomes
Develop a reproducible color workflow from source interpretation and monitoring through primary/secondary correction, shot matching, look development, LUT/conform management, responsible automation and professional delivery.

Learners will use scopes, manage transforms, match shots, create looks, evaluate AI suggestions and deliver traceable color-managed masters.

## Software track
Use a current color-managed NLE or grading application with scopes. Record source camera profiles, working space, display assumptions and output transform. Verify delivery requirements with the client/platform.

## Completion requirements
Pass the 50-point assessment, submit lab and capstone, provide source/output pipeline documentation and pass export QC. Suggested capstone pass: 80/100. Independent review and learner execution evidence remain required.
