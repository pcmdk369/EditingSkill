# CT-11 Professional Lab 02 — Restoration Tiers, Evidence Mapping and Preservation Package

- Course: CT-11 — Photo Restoration & Manipulation
- Level: Advanced / Professional
- Estimated time: 4–6 hours
- Environment: Scanner, raster editor, color-managed storage and metadata/manifest tools
- Lab status: Authored procedure; no archival certification is claimed

## 1. Scenario
A small collection contains faded prints, a damaged family photograph and one image with missing corners. Prepare preservation masters and separate access copies. Any reconstructed or AI-generated details must be visibly documented and must not be presented as recovered historical fact.

## 2. Learning objectives
- assess source condition and record damage;
- distinguish preservation capture, conservative correction and interpretive reconstruction;
- maintain provenance and a non-destructive edit history;
- assign confidence to reconstructed details;
- package preservation and access files with clear labels.

## 3. Inputs and preservation precautions
Use images you own or are authorized to process. Handle originals carefully and follow appropriate conservation practices; do not apply liquids, adhesives or physical repairs as part of this digital lab. Scan without destructive alteration where possible. Keep the original scan unchanged.

## 4. Restoration tiers
| Tier | Work | Output label |
|---|---|---|
| A — Preservation capture | Accurate scan/capture, no content alteration | Preservation master |
| B — Conservative correction | Dust, tonal fading, color cast and minor defects | Corrected access copy |
| C — Interpretive reconstruction | Rebuilding missing/obscured detail based on evidence | Reconstructed interpretation |
| D — Creative manipulation | Deliberate composite or imaginative completion | Creative composite; not historical evidence |

Do not silently promote a Tier C or D result as an unaltered historical record.

## 5. Procedure
1. Assign a unique collection ID to each source.
2. Photograph/scan the original condition and record dimensions, medium, date/source if known and custody notes.
3. Create a high-quality preservation capture using an appropriate scanner/camera workflow; record resolution, bit depth and color profile.
4. Save the capture as read-only master and create a working duplicate.
5. Map visible damage: scratches, tears, fading, stains, missing areas and previous repairs.
6. Create a repair log with region coordinates, operation, tool, date and operator.
7. Apply conservative corrections on layers or separate copies; avoid erasing evidence of condition from the preservation master.
8. For missing areas, identify supporting evidence (other prints, negatives, related images or documented context).
9. Record confidence and rationale for every reconstructed region; if evidence is insufficient, leave it incomplete or label it interpretive.
10. If AI tools are used, record provider/model/version, input, output and human corrections; inspect invented details carefully.
11. Create separate access copies sized and compressed for the intended use.
12. Generate contact sheets and compare each output with the source capture.
13. Build a manifest with IDs, checksums if available, file formats, profiles, tier labels and revision history.
14. Store redundant copies under the agreed archive and access policy.

## 6. Evidence and confidence record
| Field | Description |
|---|---|
| Region ID | Unique area of repair |
| Source evidence | Reference image/document and location |
| Method | Manual clone, patch, tonal repair or AI suggestion |
| Confidence | High / Medium / Low with rationale |
| Alteration tier | A / B / C / D |
| Reviewer | Person who checked the reconstruction |
| Disclosure | Exact label shown to recipient |

## 7. Validation
| Test | Method | Pass condition |
|---|---|---|
| Master integrity | Compare checksum/backup where available | Source capture unchanged |
| Provenance | Audit collection record | Origin and processing traceable |
| Reconstruction | Compare with supporting references | Evidence and confidence documented |
| Disclosure | Inspect filenames/metadata/labels | Tier is explicit |
| File integrity | Reopen every file | Files readable |
| Archive | Verify redundant copies | Recovery path documented |

## 8. Troubleshooting
- AI invents facial or text detail: reject or label as interpretation; do not claim recovery.
- Colorization appears plausible but unsupported: retain neutral/grayscale master and label colorization as interpretive.
- Restoration removes historical evidence: restore source capture and separate cleanup into access copy.
- Source date/identity uncertain: retain uncertainty in catalog metadata; do not infer.
- Archive file corrupt: restore from verified redundant copy and record incident.

## 9. Deliverables
Preservation masters, corrected access copies, optional labeled reconstruction, damage maps, repair log, evidence/confidence record, provenance manifest and archive verification report.

## 10. Assessment — 100 points
Source preservation 20; damage assessment 10; conservative correction 15; evidence mapping 15; reconstruction disclosure 15; file/metadata quality 10; archive/handoff 15. Pass 80/100. Unlabeled synthetic detail presented as fact is a critical failure.

## 11. Completion checklist
- [ ] Original condition recorded.
- [ ] Preservation master unchanged.
- [ ] Damage map and repair log complete.
- [ ] Restoration tier assigned to each output.
- [ ] Reconstruction supported or explicitly labeled.
- [ ] AI provenance documented where applicable.
- [ ] Access copies distinct from preservation masters.
- [ ] Archive integrity and manifest verified.
