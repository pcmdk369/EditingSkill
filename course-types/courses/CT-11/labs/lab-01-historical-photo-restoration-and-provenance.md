# CT-11 Professional Lab 01 — Historical Photo Restoration and Provenance

- Level: Advanced / Professional
- Estimated time: 4–6 hours
- Environment: Scanner or existing scan, raster editor and archive storage; record versions
- Lab status: Authored procedure; not executed in this session

## Brief
Restore one authorized damaged photograph while preserving the untouched source, documenting every intervention and distinguishing evidence-based repair from interpretation.

## Prerequisites and rights
Complete CT-11 Lessons 01–04. Use an image you own or are authorized to restore. Record provenance and any privacy/access restrictions.

## Project structure
```text
ct11-restoration/
  original/
  working/
  references/
  project/
  preservation-master/
  access-copy/
  intervention-log/
  rights/
  qc/
```

## Procedure
1. Confirm ownership, permission and intended use.
2. Preserve the original scan and create a verified working copy.
3. Record dimensions, bit depth, profile, scanner/source and date.
4. Map dust, scratches, tears, fading and missing regions.
5. Separate reversible cleanup from reconstruction.
6. Repair dust and scratches using layers and appropriate sampling.
7. Recover tone/color conservatively; document uncertain values.
8. Reconstruct missing areas only from authorized evidence or clearly labeled interpretation.
9. Compare restored output to the untouched source.
10. Create preservation and access exports.
11. Record tools, versions, operations, references and uncertainty.
12. Create a manifest and backup/checksum record where available.

## Expected artifacts
Original scan, layered restoration, preservation export, access copy, damage map, provenance record, intervention log and QC report.

## Validation
| Test | Method | Expected result |
|---|---|---|
| Original preservation | Compare original to backup | Unchanged |
| Repair quality | Inspect at full resolution | No obvious smears/repeated artifacts |
| Reconstruction | Trace to reference or label as interpretation | No fabricated fact presented as original |
| Color | Compare source and documented references | Conservative and explained |
| Archive | Open package and inspect manifest | Files traceable and readable |

## Troubleshooting
Posterization: return to higher bit-depth source. Repeated texture: vary sample. Unsupported reconstruction: revert and label uncertainty. Corrupt archive copy: restore from verified backup.

## Assessment — 100 points
Source/provenance 15; damage assessment 10; repair craft 20; historical integrity 20; non-destructive project 10; disclosure 10; archive/manifest 10; QC 5. Pass 80/100; source preservation and factual integrity are mandatory.

## Handoff
Submit all expected artifacts and a concise note explaining which areas were repaired, reconstructed or left uncertain.
