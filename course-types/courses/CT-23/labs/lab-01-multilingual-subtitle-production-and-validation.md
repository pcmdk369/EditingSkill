# CT-23 Professional Lab 01 — Multilingual Subtitle Production and Validation

- Level: Advanced / Professional
- Estimated time: 5–7 hours
- Environment: Subtitle editor, text editor and target player; record OS/app/version and locales
- Lab status: Authored procedure; not executed in this session

## Brief
Produce accurate captions and one translated subtitle file for a 2-minute interview clip. Deliver SRT and WebVTT where requested, with human review and playback validation.

## Prerequisites
Complete CT-23 Lessons 01–05. Use authorized source video/audio. Obtain a verified transcript and qualified target-language reviewer.

## Procedure
1. Confirm exact source master and version.
2. Create a timecoded transcript and verify every word.
3. Record names, technical terms and glossary.
4. Segment captions at natural phrase boundaries.
5. Time cues to speech and meaningful sound.
6. Check reading speed and line breaks against destination requirements.
7. Translate into target locale, preserving meaning and tone.
8. Obtain fluent reviewer corrections.
9. Export SRT and WebVTT with correct encoding.
10. Validate syntax, cue order and overlaps.
11. Test both files in target player against the exact master.
12. Record corrections and approvals.
13. Create manifest linking locale/file/master version.

## Expected artifacts
Verified transcript, English captions, translated subtitles, glossary, SRT/VTT files, reviewer notes, playback QA report and manifest.

## Validation
| Test | Method | Expected result |
|---|---|---|
| Transcript | Listen to source | Accurate words/speakers |
| Timing | Playback | Cue sync correct |
| Reading | Normal-speed review | Readable line length/duration |
| Translation | Fluent reviewer | Meaning and locale correct |
| Syntax | Parser/player | File opens |
| Encoding | Special-character test | No garbled text |
| Version | Compare master ID | Matches final video |

## Troubleshooting
Wrong master: retime against correct version. Encoding: export UTF-8 and test. Long translation: resegment/condense without losing meaning. Speaker error: verify source track/video.

## Assessment — 100 points
Transcript accuracy 15; timing/segmentation 15; translation quality 20; accessibility/readability 15; SRT/VTT syntax/encoding 10; human review 10; versioning/handoff 10; rights/privacy 5. Pass 80/100; meaning accuracy and rights are mandatory.

## Handoff
Submit transcript, subtitle files, glossary, review notes, QA report and version manifest.
