# CT-23 Capstone — Accessible Multilingual Video Package

- Level: Master / Professional Practice
- Estimated time: 10–16 hours
- Status: Brief authored; learner execution and review not evidenced

## Brief
Create an accessible caption and subtitle package for a 3–5 minute video in at least two languages/locales. Preserve source meaning and synchronize all files to the approved master.

## Deliverables
- exact master/version identifier;
- verified source transcript;
- caption/SDH style guide;
- glossary and locale notes;
- source-language captions;
- translated subtitle files;
- SRT/VTT or specified formats;
- human reviewer signoffs;
- syntax/encoding/playback QA report;
- rights/privacy and AI provenance record;
- delivery manifest and reflection.

## Mandatory gates
No fabricated words, incorrect attribution, unreviewed critical translation or unauthorized external processing. Each subtitle file must match the exact master.

## Rubric — 100 points
| Criterion | Points |
|---|---:|
| Transcript accuracy | 15 |
| Caption completeness/accessibility | 15 |
| Timing/segmentation | 15 |
| Translation/localization | 20 |
| Format/encoding validation | 10 |
| Human review/provenance | 10 |
| Rights/privacy | 5 |
| Manifest/handoff/reflection | 10 |

Pass 80/100. Meaning, rights and master-version accuracy are mandatory.

## Review
Reviewer samples every language, checks source audio, validates file syntax/encoding and plays subtitles against final master. Actual learner files and reviewer evidence are required.
