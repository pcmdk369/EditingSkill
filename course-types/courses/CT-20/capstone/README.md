# CT-20 Capstone — Integrated VFX Shot

- Level: Master / Professional Practice
- Estimated time: 12–20 hours
- Status: Brief authored; learner execution and review not evidenced

## Brief
Create one 5–10 second VFX shot integrating live-action footage with a keyed/roto or tracked visual element. The composite must match perspective, color, grain, blur and timing.

## Deliverables
- shot breakdown and source plate metadata;
- tracking/matte data;
- editable comp project;
- CG/render assets or authorized elements;
- color/alpha pipeline notes;
- final image sequence and review video;
- dependency manifest and version history;
- AI/provenance note if applicable;
- QC report and reflection.

## Mandatory gates
Use authorized footage and assets. Identity-sensitive alterations require explicit authorization. Preserve source plate and document synthetic/reconstructed content.

## Rubric — 100 points
| Criterion | Points |
|---|---:|
| Shot breakdown and pipeline | 10 |
| Matte/roto quality | 15 |
| Tracking/matchmove | 15 |
| Element integration | 20 |
| Color/alpha/render quality | 15 |
| Temporal consistency | 10 |
| Rights/provenance | 5 |
| Delivery/archive/reflection | 10 |

Pass 80/100. Rights, alpha integrity and complete frame sequence are mandatory.

## Review
Reviewer checks full shot, matte/track, edge quality, color/alpha, frame sequence, source/project and rights. Actual learner files and review evidence are required.
