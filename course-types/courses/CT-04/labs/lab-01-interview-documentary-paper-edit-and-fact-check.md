# CT-04 Professional Lab 01 — Interview Documentary Paper Edit and Fact-Check

- Course: CT-04 — Documentary & Interview Editing
- Level: Intermediate / Professional
- Estimated time: 4–6 hours
- Environment: Any NLE, spreadsheet or transcript editor; record OS and versions
- Lab status: Authored procedure; not executed or independently tested in this session

## 1. Professional brief
Create a 90-second interview-led sequence from authorized learner-recorded interviews and supporting B-roll. The sequence must preserve participant meaning, identify source passages, and distinguish verified fact from opinion or unresolved claim.

## 2. Objectives
Create a transcript, selects log, paper edit, rough cut, claim ledger and review record. Demonstrate traceability from every important quote to the original source.

## 3. Prerequisites and setup
Complete CT-04 Lessons 01–05. Prepare secure storage, a backup, a project folder and a written brief. Record the editing application/version. Do not upload private interviews to external transcription tools without authorization.

## 4. Inputs and rights
Use learner-created interviews with informed consent or appropriately licensed material. Record release scope, restrictions, music/footage rights and source metadata. Remove or protect personal data not required for the exercise.

## 6. Implementation procedure
1. Copy and verify source media; preserve originals.
2. Create a source inventory with filenames, duration, date, speaker and consent status.
3. Watch every interview in full and create a transcript with speaker and timecode.
4. Flag inaudible or uncertain words; never guess.
5. Create at least 10 selects grouped by theme, retaining full context.
6. Build a paper edit with quote IDs, source timecodes and intended story function.
7. Draft a claim ledger for every factual statement in the planned sequence.
8. Verify claims against primary/independent sources or label them as testimony/opinion.
9. Assemble dialogue before B-roll; avoid using cutaways to imply false reactions.
10. Add B-roll only after documenting whether it is contemporaneous, archival or illustrative.
11. Export a review cut and obtain one viewer-comprehension review.
12. Correct factual/context issues and document each revision.

## 7. Expected artifacts
Transcript, selects log, paper edit, 90-second rough cut, claim ledger, rights/consent log, B-roll provenance log and QC report.

## 8. Validation
| Test | Method | Expected result | Evidence |
|---|---|---|---|
| Quote traceability | Sample every quote against source | Correct speaker/timecode/context | Select log |
| Claim integrity | Review claim ledger | No unsupported fact stated as proven | Source records |
| B-roll context | Audit every cutaway | No misleading date/place implication | Provenance log |
| Consent/rights | Inspect asset records | Authorized use within scope | Release/license log |
| Playback | Watch full export | No missing media or sync issue | QC notes |

## 9. Troubleshooting and rollback
If a quote is disputed, return to the full source passage and preserve the original edit. If a claim lacks evidence, attribute, qualify or remove it. If consent is unclear, stop use of the affected material. Keep failed versions separate from approved exports.

## 10. Submission and rubric
Submit all expected artifacts. Score: source accuracy 25; story structure 20; factual verification 20; ethical/rights process 15; technical edit 10; documentation 10. Pass 80/100; unauthorized media use or fabricated quote is a critical failure.

## 11. Completion checklist
- [ ] Source inventory and consent status complete.
- [ ] Transcript reviewed against audio.
- [ ] Selects retain context and timecodes.
- [ ] Claim ledger has sources and limitations.
- [ ] B-roll context is documented.
- [ ] Export watched and reviewed.
- [ ] Revisions and unresolved issues recorded.
