# CT-10 Capstone — Professional Product Catalog Image Set

- Level: Master / Professional Practice
- Estimated time: 10–16 hours
- Status: Brief authored; learner execution and review not evidenced

## Brief
Create a product catalog image package for at least 10 SKUs, including multiple variants and hero/detail views. All images must accurately represent the product and map to verified catalog identifiers.

## Deliverables
- brief and marketplace/client specifications;
- SKU master and source-to-output mapping;
- source inventory and rights log;
- hero/detail image set for 10+ SKUs;
- editable layered project and batch settings;
- color/reference notes;
- exception log and reconciliation report;
- export manifest and QC report;
- archive and update plan;
- reflection and portfolio permission status.

## Mandatory gates
No wrong variant, invented feature, false scale or unauthorized asset. Preserve originals. Verify current marketplace requirements.

## Rubric — 100 points
| Criterion | Points |
|---|---:|
| Brief and catalog mapping | 15 |
| Product/variant accuracy | 20 |
| Background/edge quality | 15 |
| Color/material fidelity | 15 |
| Consistency and batch workflow | 10 |
| Rights/provenance | 10 |
| Export QC and reconciliation | 10 |
| Documentation/handoff | 5 |

Pass 80/100. Product accuracy and rights are mandatory gates.

## Review
Reviewer samples every SKU mapping and checks all outputs for variant fidelity, color, dimensions, rights and manifest completeness. Validation requires actual learner files and documented review.
