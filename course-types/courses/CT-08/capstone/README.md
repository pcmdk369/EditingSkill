# CT-08 Capstone — Original Visual Identity and Campaign Graphics

- Level: Master / Professional Practice
- Estimated time: 10–16 hours
- Status: Brief authored; learner execution and review not evidenced

## Brief
Create an original identity and campaign graphic package for a fictional organization or an authorized client. The package must work across screen formats and include a documented print-ready variant if required.

## Deliverables
- brief and audience definition;
- concept sketches and reference board;
- logo, icon and responsive variants;
- typography/color/spacing design system;
- three campaign layouts;
- editable vector and raster source;
- SVG/PDF/PNG exports;
- font/image/icon license schedule;
- contrast/accessibility review;
- preflight and delivery manifest;
- 500-word reflection and portfolio case study.

## Mandatory criteria
Do not imitate protected identity, redistribute restricted fonts/assets or misrepresent generated content as original human-authored work. Verify print specifications and permissions.

## Rubric — 100 points
| Criterion | Points |
|---|---:|
| Research, concept and originality | 15 |
| Vector craft and scalability | 15 |
| Typography and layout hierarchy | 15 |
| Color/accessibility | 10 |
| System consistency and adaptability | 15 |
| Rights and asset provenance | 10 |
| Export/preflight quality | 10 |
| Documentation and handoff | 10 |

Pass: 80/100. Rights and originality are mandatory review gates.

## Review
Reviewer inspects editable files, independent SVG/PDF rendering, output sizes, contrast, licensing and project packaging. Actual learner evidence is required for validation.
