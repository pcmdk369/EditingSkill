# CT-08 Lesson 02 — Shapes, Paths, Typography and Layout

- Course: CT-08 — Digital Illustration & Graphic Editing
- Level: Beginner / Intermediate
- Estimated time: 120–180 minutes
- Prerequisites: Previous CT-08 lessons and authorized graphic assets
- Tools/environment: Vector/raster design application; record OS, app/version, color profile and output target
- Version/review date: Tool-neutral; verify current software and print-vendor specifications

## Learning outcomes
Build clean vector shapes, edit paths, select type, establish hierarchy and align graphic elements to a grid.

## Key definitions
- **Vector:** Artwork represented by paths/shapes rather than a fixed pixel grid.
- **Raster:** Pixel-based image.
- **Artboard:** Defined design canvas within a document.
- **Bézier curve:** Path controlled by anchor points and direction handles.
- **Typography hierarchy:** Organization of text by visual importance.
- **Design token:** Reusable named value for color, type, spacing or other design rule.
- **Preflight:** Inspection of a production file before delivery.
- **Bleed:** Artwork extending beyond the final trim edge.

## Purpose and theory
Shape construction and typography are core graphic skills. Bézier curves use anchor points and handles to control path direction. Typography hierarchy uses size, weight, spacing and position to guide attention. Alignment and spacing should be consistent but not mechanically uniform.

## Tools, requirements and alternatives
Use a vector editor for scalable shapes and logos, a raster editor for pixel-based image work, and layout software where multi-page publishing is required. Record versions and licenses. Verify printer specifications before setting final print output.

## Procedure
1. Create basic geometric shapes. 2. Combine/subtract shapes using path operations. 3. Edit anchor points and handles with minimal nodes. 4. Choose typefaces appropriate to audience and license. 5. Establish headline, subhead and body hierarchy. 6. Apply grid, alignment and spacing. 7. Check legibility at target size. 8. Save styles and reusable components.

## Worked example
A poster uses one display face for title, one readable text face and a limited set of geometric forms. Alignment guides the viewer from title to event details.

## Dry run
Too many anchor points create lumpy curves. Simplify nodes and adjust handles. Dense text loses hierarchy; reduce copy and rework spacing.

## Guided practice
Create a typographic event poster and a vector icon set.

## Independent assignment
Repeat the process for a different audience or output medium. Submit editable source, exports, asset/license log and a short rationale.

## Knowledge check
1. When is vector artwork preferable to raster?
2. What is the role of an artboard and bleed?
3. How does typography hierarchy improve communication?
4. Why should color not be the only information cue?
5. What should be included in a professional asset/license record?

## Answer guidance
1. For scalable shapes, logos and illustrations where vector output is appropriate.
2. Artboard defines design area; bleed extends artwork beyond trim for print.
3. It guides attention and makes information easier to scan.
4. Accessibility and color-vision differences may prevent reliable interpretation.
5. Asset origin, owner, license, permitted uses, restrictions and version.
