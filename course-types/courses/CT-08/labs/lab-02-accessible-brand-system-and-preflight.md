# CT-08 Professional Lab 02 — Accessible Brand System and Multi-Output Preflight

- Course: CT-08 — Digital Illustration & Graphic Editing
- Level: Advanced / Professional
- Estimated time: 4–6 hours
- Environment: Vector editor, raster editor as needed, font/asset license records and output preflight tools
- Lab status: Authored procedure; not executed or vendor-certified in this session

## 1. Brief
Create a small original identity system for a fictional organization and deliver editable vector artwork, accessible digital graphics and a print-ready proof. The system must remain coherent across a logo lockup, social tile, simple flyer and monochrome mark.

## 2. Learning objectives
- construct a scalable vector identity using reusable components;
- define typography, spacing, color and minimum-size rules;
- evaluate contrast and non-color cues;
- distinguish RGB/screen delivery from print requirements;
- audit font, stock and generated-asset licenses;
- preflight and package editable source files.

## 3. Inputs and constraints
Use original artwork or assets with documented licenses. Do not imitate a real brand's distinctive mark. Define audience, intended use, required languages, output sizes and print vendor specifications before design.

## 4. System specification
Create a one-page design system containing:
- primary and secondary logo lockups;
- clear-space and minimum-size rules;
- color tokens with RGB/HEX and print equivalents where specified;
- typography hierarchy and licensed font sources;
- spacing/grid tokens;
- icon/illustration style;
- accessibility notes and usage restrictions.

## 5. Implementation procedure
1. Create a vector master using named layers and editable paths/text.
2. Use a grid and optical alignment; avoid arbitrary scaling of logo elements.
3. Define reusable color and typography styles.
4. Check text/background contrast with a recognized accessibility method and record results; do not rely on color alone to convey meaning.
5. Test the mark at small sizes, monochrome and on light/dark backgrounds.
6. Create social and flyer layouts from reusable components.
7. Confirm font licenses permit the intended embedding, outlining or transfer.
8. Audit placed images, icons and generated assets for provenance and use rights.
9. Prepare screen exports using the requested dimensions and color profile.
10. Prepare print artwork using the vendor's exact bleed, trim, color and PDF requirements.
11. Preflight missing links, font issues, overprint/transparency, bleed, resolution and spelling.
12. Reopen all exports and compare them with the source design.
13. Package editable sources, linked assets, fonts/license notes and output manifest.

## 6. Required outputs
- editable vector identity master;
- logo lockups and monochrome variant;
- one social tile;
- one print flyer;
- one-page design system;
- rights register;
- accessibility/contrast test record;
- screen exports and print proof;
- preflight report and delivery manifest.

## 7. Validation matrix
| Test | Method | Expected result |
|---|---|---|
| Scalability | Inspect vector at multiple sizes | Clean edges and readable mark |
| Clear space | Compare with specification | No unintended crowding |
| Contrast | Test text/background combinations | Meets chosen target for intended use |
| Color independence | Inspect grayscale and color-vision simulation | Meaning not conveyed by color alone |
| Fonts | Check license and package | Permitted use documented |
| Links | Open packaged source on clean location | No missing assets |
| Print | Preflight vendor requirements | No unresolved critical issue |
| Screen | Inspect exported dimensions/profile | Matches brief |
| Text | Proofread all artwork | Correct copy and language |

## 8. Troubleshooting
- Text reflows on another device: verify font licensing/availability and embed or package as permitted.
- Colors shift in print: use vendor profile/specification and request a proof.
- Logo fails at small size: simplify detail or create a size-specific variant.
- Contrast is insufficient: change text/background values or add a non-color cue.
- Linked image missing: package the asset and verify paths.
- Export differs from artwork: inspect transparency, overprint, profile conversion and PDF preset.

## 9. Assessment — 100 points
Identity coherence 15; vector craft 15; typography/layout 15; accessibility 15; multi-output adaptation 15; rights/provenance 10; preflight/QC 10; handoff 5. Pass 80/100. Font/asset misuse or inaccessible critical information requires remediation.

## 10. Completion checklist
- [ ] Brief and audience defined.
- [ ] Editable vector source organized.
- [ ] Design tokens and logo rules documented.
- [ ] Contrast/accessibility tests recorded.
- [ ] Fonts and assets rights checked.
- [ ] Screen and print specifications followed.
- [ ] All exports reopened and inspected.
- [ ] Preflight and manifest complete.

## 11. Professional note
Accessibility targets and print requirements depend on the intended audience, jurisdiction, medium and vendor. Record the standard used and obtain specialist review where needed.
