# CT-08 Professional Lab 01 — Vector Brand System and Export Preflight

- Level: Advanced / Professional
- Estimated time: 4–6 hours
- Environment: Vector editor and optional layout/raster editor; record OS/app/version
- Lab status: Authored procedure; not executed in this session

## Brief
Create a small identity system for a fictional organization: logo, icon, typography/color rules and three social layouts. Deliver editable vector source, SVG/PDF and raster previews. Do not imitate an existing trademark.

## Prerequisites and inputs
Complete CT-08 Lessons 01–05. Use original shapes, licensed fonts and authorized assets. Record output dimensions, intended screen/print use and any printer requirements.

## Implementation
1. Define audience, purpose and identity attributes.
2. Sketch three distinct concepts and choose one using explicit criteria.
3. Build logo and icon with clean vector paths.
4. Establish color and typography tokens.
5. Create responsive logo variants and minimum-size rules.
6. Build three layouts using a consistent grid and spacing system.
7. Check contrast and provide non-color cues where information is conveyed.
8. Test at actual display sizes and in grayscale.
9. Verify fonts, linked assets, SVG rendering and PDF output.
10. Export sample files and inspect them in independent viewers.
11. Complete preflight and license schedule.
12. Package native source and approved exports.

## Expected artifacts
Editable vector project, logo variants, icon, mini brand guide, three layouts, SVG/PDF/PNG exports, license schedule and preflight report.

## Validation
| Test | Method | Expected result |
|---|---|---|
| Vector integrity | Open SVG in independent viewer | Paths render as intended |
| Typography | Inspect fonts and small-size output | Legible and licensed |
| Color/contrast | Check palette and grayscale | Clear hierarchy |
| Export | Open PDF/PNG/SVG | Correct dimensions and appearance |
| Rights | Review fonts/assets | Permitted use documented |
| Handoff | Reopen packaged project | Dependencies resolved |

## Troubleshooting
Missing font: replace with licensed alternative or package if permitted. SVG mismatch: inspect unsupported effects and simplify. Pixelated logo: export from vector master. Weak contrast: adjust luminance and hierarchy. Printer requirements unclear: request specification before print export.

## Assessment — 100 points
Concept/originality 15; vector craft 20; typography/layout 15; color/accessibility 15; responsive variants 10; export/preflight 10; licensing 5; handoff 10. Pass 80/100.

## Handoff
Submit native source, brand guide, three layouts, all exports, license schedule, preflight results and design rationale.
