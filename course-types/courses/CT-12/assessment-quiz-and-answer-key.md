# CT-12 — Color Correction & Color Grading Assessment

**Total:** 50 points | **Suggested time:** 45–60 minutes

## Part A — Multiple choice (10 × 2 = 20)

1. Color correction primarily: A. Normalizes/matches B. Adds story dialogue C. Changes rights D. Creates subtitles.
2. Grading primarily: A. Creative color shaping B. File naming C. Sync D. Proxy generation.
3. Waveform is useful for: A. Signal level B. Copyright C. Shot ownership D. Font license.
4. RGB parade separates: A. Red/green/blue channels B. Audio tracks C. Camera angles D. Layers.
5. Vectorscope shows: A. Chroma/hue B. Frame rate C. Duration D. File size.
6. A LUT is: A. Color-value mapping B. Legal release C. Subtitle format D. Codec.
7. Technical match should generally precede: A. Creative look B. File backup C. Source ingest D. Consent.
8. A LUT applied to wrong input can: A. Create incorrect color B. Improve automatically C. Grant rights D. Fix all footage.
9. Shot matching should be checked: A. In motion B. Only in one still C. Only by file name D. Without source.
10. A color handoff should include: A. Output transform and settings B. Only a screenshot C. No metadata D. Random LUT.

## Part B — Short answer (5 × 3 = 15)

11. Explain color space and color profile in the context of an image/video pipeline.
12. Name three scope types and what they help inspect.
13. Why is skin tone not one universal numeric target?
14. What is the risk of applying the same LUT to different source encodings?
15. Name three items in a professional color archive.

## Part C — Applied case (15)

16. A log clip looks washed out, and a creative LUT makes it oversaturated. Describe the diagnostic sequence. (8)
17. A graded master looks different after round-trip to another application. What should be checked? (7)

## Answer key
1 A; 2 A; 3 A; 4 A; 5 A; 6 A; 7 A; 8 A; 9 A; 10 A.
11. Color space defines color encoding/range; profile/transform describes how values are interpreted in a pipeline. (3)
12. Waveform, RGB parade, vectorscope and their relevant signal/chroma information. (3)
13. Lighting, complexion and creative intent vary; preserve source fidelity and context. (3)
14. LUT input assumptions may not match source; color becomes incorrect. (3)
15. Project, output settings, reference stills, LUTs, node graph, metadata/QC. (3)
16. Confirm source log profile, input transform, working space, LUT expected input, node order and output transform; normalize correctly and compare scopes/reference. (8)
17. Check color space/gamma transforms, data levels, metadata, LUT application, codec and reference stills. (7)

## Performance bands
45–50 exemplary; 40–44 competent; 35–39 developing; below 35 remediation. Incorrect output transform requires correction before delivery.
