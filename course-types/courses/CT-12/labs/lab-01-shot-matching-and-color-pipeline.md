# CT-12 Professional Lab 01 — Shot Matching and Color Pipeline

- Level: Advanced / Professional
- Estimated time: 4–6 hours
- Environment: Color-managed NLE/grading application; record OS/app/version, display and output target
- Lab status: Authored procedure; not executed in this session

## Brief
Match a five-shot scene from at least two camera sources, create one approved creative look and export a reference-matched master.

## Prerequisites and setup
Complete CT-12 Lessons 01–05. Obtain authorized footage, camera notes and output specification. Record source color space/log profile and monitoring assumptions.

## Procedure
1. Inventory clips and identify camera/source profiles.
2. Set working and output color management according to the brief.
3. Choose a representative reference frame.
4. Normalize each shot before creative grading.
5. Use waveform/RGB parade to inspect exposure and channel balance.
6. Use vectorscope and visual references to assess chroma.
7. Match skin, neutral objects and important colors.
8. Apply creative look on a separate node/group or reversible stage.
9. Review shot transitions in motion.
10. Create reference stills and compare with approved intent.
11. Export a short proof; inspect metadata and playback.
12. Export final and package project/LUT dependencies.

## Expected artifacts
Five-shot graded timeline, reference stills, node graph, source/output color notes, LUT register, export and QC report.

## Validation
| Test | Method | Expected result |
|---|---|---|
| Source transform | Inspect pipeline | Correct input interpretation |
| Exposure/color | Scopes and reference | No unintended clipping/cast |
| Shot match | Playback sequence | No distracting jumps |
| Look | Compare reference stills | Consistent approved intent |
| Export | Metadata and full playback | Matches delivery spec |
| Archive | Reopen project/package | Dependencies documented |

## Troubleshooting
Double LUT: inspect transform order. Gamma shift: test round-trip and range. Skin drift: isolate secondary and compare source. Missing LUT: document/provide permitted dependency. HDR/SDR mismatch: obtain exact mastering specification.

## Assessment — 100 points
Pipeline 20; primary correction 15; shot matching 20; look development 15; scopes/reference evidence 10; export QC 10; project/manifest 10. Pass 80/100.

## Handoff
Submit project, exports, reference stills, node/LUT documentation, settings and QC report.
