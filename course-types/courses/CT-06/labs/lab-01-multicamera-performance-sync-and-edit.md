# CT-06 Professional Lab 01 — Multicamera Performance Sync and Edit

- Level: Intermediate / Professional
- Estimated time: 4–6 hours
- Environment: NLE with multicamera or synchronized tracks; record OS/app/version
- Lab status: Authored procedure; not executed or tool-tested in this session

## 1. Brief
Edit a 60–90 second performance using at least three authorized camera angles and one approved audio master. Preserve sync, performance continuity and a coherent musical arc.

## 2. Prerequisites
Complete CT-06 Lessons 01–03. Obtain source media, approved audio master, rights records and camera notes. Preserve all original files.

## 3. Project structure
```text
ct06-performance-lab/
  source-video/
  approved-audio/
  project/
  exports/review/
  exports/final/
  rights/
  sync-notes/
  qc/
```

## 4. Implementation
1. Inventory clips and record frame rate, duration, resolution and audio.
2. Confirm the approved audio master and its version.
3. Align camera angles using a clap, timecode or verified waveform event.
4. Check sync at start, middle and end of each recording.
5. Build a synchronized multicamera sequence or equivalent track layout.
6. Mark song sections, beats, phrases and performance highlights.
7. Create a wide/medium/close shot map.
8. Edit for performance, emotion and action continuity; do not cut mechanically to every beat.
9. Check visible lip-sync and instrument action.
10. Export a review copy and inspect complete playback.
11. Correct sync/continuity defects and record changes.
12. Export final and complete rights/QC manifest.

## 5. Expected artifacts
Synchronized project, 60–90 second edit, marker map, angle log, sync report, rights register and QC report.

## 6. Validation
| Test | Method | Expected result |
|---|---|---|
| Sync | Compare at beginning/middle/end | No unintended drift |
| Performance | Inspect instrument/lip action | Visual action matches approved audio |
| Continuity | Review adjacent cuts | No false action or geography |
| Audio | Full playback | Correct master, no unintended clipping |
| Rights | Check licenses/releases | All assets authorized |
| Export | Metadata + full playback | Meets brief |

## 7. Troubleshooting
Drift: inspect variable frame rate/recorder clock. Wrong audio: compare approved master identity. Repetitive cuts: map shot functions. Performance mismatch: use correct take or choose another angle. Preserve the source and prior edit when correcting.

## 8. Assessment — 100 points
Sync 25; performance continuity 20; musical structure 15; shot selection 15; rights 10; technical export 10; documentation 5. Pass 80/100; rights and sync are mandatory gates.

## 9. Handoff
Submit editable project, final export, sync evidence, rights log, marker/angle map and QC notes.
