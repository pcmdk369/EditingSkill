# CT-24 Professional Lab 02 — AI Image Batch Evaluation and Risk Gates

- Course: CT-24 — AI-Assisted Image Editing
- Level: Expert / Professional
- Estimated time: 4–6 hours
- Environment: Authorized image tool(s), raster editor, source/reference set and evaluation spreadsheet
- Lab status: Authored procedure; no model provider or generated result is endorsed or tested

## Brief
Evaluate an AI-assisted image workflow on a small set of non-sensitive, learner-created images. Compare output quality, consistency, editability, privacy and rights. Do not use private or third-party material without authorization.

## Learning objectives
Design a repeatable evaluation, identify synthetic defects, compare providers/settings fairly, document provenance and define human approval gates.

## Procedure
1. Define the intended task and objective quality criteria.
2. Select non-sensitive authorized source images and preserve originals.
3. Review provider terms for retention, training, commercial rights, output ownership and restrictions.
4. Record provider/model/version, date, settings and input identifiers.
5. Define a bounded prompt/task and keep evaluation conditions consistent.
6. Generate multiple outputs only within approved usage/cost limits.
7. Compare anatomy, text, geometry, reflections, texture, shadows and background continuity.
8. Compare outputs against source/reference facts; reject invented features or false evidence.
9. Evaluate resolution, artifact level, edge quality and editability.
10. Record time saved and human correction time; do not equate speed with quality.
11. Score privacy, rights, repeatability, consistency and quality separately.
12. Establish release gates: source authorization, output inspection, disclosure decision and human approval.
13. Preserve original, draft, corrected output and provenance log.
14. Produce a recommendation with limitations and rollback plan.

## Risk register
| Risk | Example | Gate |
|---|---|---|
| Privacy | Personal image uploaded to external service | Explicit authorization and terms review |
| Rights | Output uses restricted source/asset | License/permission review |
| Synthetic error | Added object or false product detail | Source comparison and reject/correct |
| Identity change | Unapproved face/body alteration | Consent and scope review |
| Bias/representation | Generated features distort intended subject | Human review and corrective decision |
| Reproducibility | Model/version changes output | Record configuration; preserve approved result |

## Validation
| Test | Method | Pass condition |
|---|---|---|
| Repeatability | Repeat same task where permitted | Variation recorded |
| Factual fidelity | Compare to source | No unsupported factual change |
| Visual quality | Inspect at 100% and output size | No critical artifacts |
| Rights/privacy | Audit provider and asset records | Authorized use |
| Provenance | Trace input-to-output | Complete chain |
| Human review | Independent reviewer | Approval or rejection recorded |

## Deliverables
Evaluation plan, source inventory, provider terms summary, prompt/settings log, scored output set, defect log, provenance record, risk assessment and recommendation.

## Assessment — 100 points
Task design 10; provider/rights review 15; output evaluation 20; factual fidelity 15; privacy/safety gates 15; provenance 10; recommendation/rollback 15. Pass 80/100. Unauthorized data processing or unreviewed misleading output is a critical failure.

## Completion checklist
- [ ] Source authorization confirmed.
- [ ] Provider terms reviewed.
- [ ] Model/version/settings recorded.
- [ ] Outputs compared against source.
- [ ] Synthetic defects documented.
- [ ] Human approval gates defined.
- [ ] Provenance and rollback preserved.
