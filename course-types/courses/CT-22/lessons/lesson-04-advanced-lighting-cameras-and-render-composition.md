# CT-22 Lesson 04 — Lighting, Cameras and Render Composition

- Course: CT-22 — 3D Modeling, Materials & Rendering
- Level: Advanced
- Estimated time: 120–180 minutes
- Prerequisites: Previous CT-22 lessons and authorized 3D assets
- Tools/environment: Current 3D modeling application with mesh, UV, materials and render support; record OS/app/version/hardware
- Version/review date: Tool-neutral; interchange and renderer behavior varies

## Learning outcomes
Set camera framing and lighting to communicate form, scale and material while controlling shadows, reflections and render quality.

## Key definitions
- **Vertex/edge/face:** Basic polygon mesh components.
- **Topology:** Arrangement of mesh components.
- **Edge loop:** Connected path of edges.
- **Bevel:** Rounded/chamfered edge treatment.
- **UV map:** 2D coordinates mapping textures to 3D surfaces.
- **Texel density:** Texture pixel density across a model surface.
- **Material:** Surface response definition for a renderer.
- **Procedural modeling:** Geometry generation through parameters/rules.
- **LOD:** Level of detail representation.

## Purpose and theory
Lighting reveals geometry and material. Key/fill/rim roles are common starting points, not fixed rules. Camera focal length and distance affect perspective. Render settings balance noise, quality and time. Use test renders to evaluate composition before increasing samples.

## Tools, requirements and alternatives
Use a current 3D application with modeling, UV, material and render capability. Record units, axis convention, renderer and app/version. Use original or licensed assets and preserve source projects.

## Procedure
1. Define visual intent and camera. 2. Set object scale and camera framing. 3. Add key/fill/rim or environment lighting. 4. Tune shadow softness and reflections. 5. Check material response. 6. Render low-cost tests. 7. Adjust composition and exposure. 8. Record renderer settings.

## Worked example
A metallic product uses broad soft sources to create readable reflections and a grounded shadow.

## Dry run
Metal looks flat because it reflects a uniform environment. Add controlled reflection shapes and adjust roughness.

## Guided practice
Create a studio product render with three lighting setups.

## Independent assignment
