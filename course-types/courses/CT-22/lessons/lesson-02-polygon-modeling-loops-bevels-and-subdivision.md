# CT-22 Lesson 02 — Polygon Modeling, Edge Loops, Bevels and Subdivision

- Course: CT-22 — 3D Modeling, Materials & Rendering
- Level: Beginner / Intermediate
- Estimated time: 120–180 minutes
- Prerequisites: Previous CT-22 lessons and authorized 3D assets
- Tools/environment: Current 3D modeling application with mesh, UV, materials and render support; record OS/app/version/hardware
- Version/review date: Tool-neutral; interchange and renderer behavior varies

## Learning outcomes
Use extrusion, loop cuts, bevels and subdivision to create controlled forms with clean shading.

## Key definitions
- **Vertex/edge/face:** Basic polygon mesh components.
- **Topology:** Arrangement of mesh components.
- **Edge loop:** Connected path of edges.
- **Bevel:** Rounded/chamfered edge treatment.
- **UV map:** 2D coordinates mapping textures to 3D surfaces.
- **Texel density:** Texture pixel density across a model surface.
- **Material:** Surface response definition for a renderer.
- **Procedural modeling:** Geometry generation through parameters/rules.
- **LOD:** Level of detail representation.

## Purpose and theory
Polygon modeling builds surfaces by editing mesh topology. Edge loops define form and deformation. Bevels soften edges; subdivision smooths surfaces but depends on support loops and topology. Excessive geometry can make modeling and shading harder.

## Tools, requirements and alternatives
Use a current 3D application with modeling, UV, material and render capability. Record units, axis convention, renderer and app/version. Use original or licensed assets and preserve source projects.

## Procedure
1. Block primary shape. 2. Add edge loops where form changes. 3. Extrude details. 4. Bevel hard edges appropriately. 5. Add subdivision and inspect curvature. 6. Correct pinching/poles. 7. Check normals and smoothing. 8. Save high/low or working versions.

## Worked example
A hard-surface prop uses bevels to catch highlights and support loops to maintain flat areas under subdivision.

## Dry run
Pinching occurs around poles. Redirect edge flow or change support geometry.

## Guided practice
Create a hard-surface object with controlled bevel and subdivision.
