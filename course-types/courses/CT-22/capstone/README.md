# CT-22 Capstone — Production-Ready 3D Asset and Render Package

- Level: Master / Professional Practice
- Estimated time: 12–18 hours
- Status: Brief authored; learner execution and review not evidenced

## Brief
Create a production-ready 3D asset or small prop set with clean topology, UVs, materials, lighting and render outputs. Deliver native and interchange files where required.

## Deliverables
- brief, dimensions and reference board;
- native editable model project;
- wireframe/topology evidence;
- UV layouts and texture maps;
- material setup and color-space notes;
- camera/light setup and final renders;
- optimization/procedural notes;
- interchange export and reimport test;
- rights/provenance record;
- manifest, QC report and reflection.

## Mandatory gates
Use authorized reference/texture assets. Preserve editable source and test target-app compatibility.

## Rubric — 100 points
| Criterion | Points |
|---|---:|
| Modeling/form accuracy | 15 |
| Topology and normals | 15 |
| UV/texture quality | 15 |
| Materials and lighting | 15 |
| Render quality | 15 |
| Optimization/interchange | 10 |
| Rights/provenance | 5 |
| Documentation/handoff | 10 |

Pass 80/100. Rights and interchange integrity are mandatory gates.

## Review
Reviewer inspects native scene, mesh, UVs, materials, renders, target-app reimport and package completeness. Actual learner files and review evidence are required.
