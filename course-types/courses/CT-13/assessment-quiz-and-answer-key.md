# CT-13 — Audio Editing Assessment

**Total:** 50 points | **Suggested time:** 45–60 minutes

## Part A — Multiple choice (10 × 2 = 20)

1. Sample rate measures: A. Samples per second B. Number of channels C. Peak level D. Track count.
2. Bit depth relates to: A. Sample quantization B. Duration C. Stereo width D. File name.
3. A crossfade: A. Blends adjacent clips B. Changes sample rate C. Grants rights D. Adds captions.
4. EQ adjusts: A. Frequency balance B. Clip ownership C. Frame rate D. Aspect ratio.
5. Compression controls: A. Dynamic range B. Color profile C. Video sync only D. File path.
6. Integrated loudness estimates: A. Perceived program loudness B. Instantaneous peak C. Sample rate D. Stereo image.
7. True peak accounts for: A. Reconstructed inter-sample peaks B. Only track names C. Color clipping D. Caption timing.
8. Noise reduction can: A. Create artifacts B. Guarantee clean speech C. Restore missing words D. Establish consent.
9. A final delivery should be measured: A. On rendered file B. Only in timeline C. By guessing D. Only by file size.
10. Voice cloning requires: A. Explicit authorization B. Only a prompt C. No review D. No disclosure ever.

## Part B — Short answer (5 × 3 = 15)

11. Explain why sample rate and bit depth are not interchangeable.
12. Name three causes of audio clicks or pops.
13. Why should denoise be used conservatively?
14. Distinguish peak, loudness and true peak.
15. What belongs in a session handoff?

## Part C — Applied case (15)

16. A dialogue mix meets the target in the DAW but the encoded export exceeds the true-peak ceiling. Explain a safe correction and retest. (8)
17. AI transcription attributes a sentence to the wrong speaker. What should be corrected and documented? (7)

## Answer key
1 A; 2 A; 3 A; 4 A; 5 A; 6 A; 7 A; 8 A; 9 A; 10 A.
11. Sample rate is time sampling frequency; bit depth is quantization resolution. (3)
12. Abrupt waveform discontinuity, bad edit boundary, buffer/dropout, clipped source. (3)
13. Excessive processing can damage speech and create artifacts. (3)
14. Peak is sample maximum; loudness is perceived program level; true peak estimates reconstructed inter-sample maximum. (3)
15. Session, media, plugin/dependency list, settings, stems, rights, QC and manifest. (3)
16. Measure rendered file, inspect encoding/limiter ceiling, reduce level or adjust processing, render proof and remeasure. (8)
17. Compare with original recording/video, correct speaker/timecode, review transcript and captions, log tool/version and human correction. (7)

## Performance bands
45–50 exemplary; 40–44 competent; 35–39 developing; below 35 remediation. Technical compliance and rights are mandatory.
