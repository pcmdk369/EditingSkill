# Editing Skill™ — Complete Course-Type Catalog

This directory defines the individual courses available inside the universal Editing Skill™ program. Each course is a standalone pathway and can also be combined into a professional specialization.

## Course structure

Every course follows the same progression:

1. Foundation — terminology, media fundamentals, safe setup
2. Beginner — interface, core tools, guided exercises
3. Intermediate — structured workflows and multi-step projects
4. Advanced — professional techniques and complex assignments
5. Expert — client briefs, specialized production and revisions
6. Master — creative direction, pipeline design and capstone
7. AI & Automation — responsible AI assistance and repeatable workflows
8. Professional Practice — delivery, quality control, portfolio and studio readiness

Each course should include lessons, demonstrations, practice assets, assignments, project files where licensing permits, quizzes, answer keys, assessment rubrics, troubleshooting, and a final portfolio project.

## Software tracks

Software is taught as an implementation track within a course, not as a replacement for the underlying skill. Relevant tracks may include DaVinci Resolve, Adobe Premiere Pro, After Effects, Photoshop, Lightroom, Illustrator, Audacity, REAPER, Blender, GIMP, Krita, CapCut, VN and FFmpeg. Availability, pricing and features must be checked before publishing software-specific instructions.

## Course completion

A learner completes a course by passing its knowledge checks, submitting required practical work, meeting the quality rubric, and explaining key creative and technical decisions. A course must not be marked complete solely because lessons were viewed.

## Content development status

This catalog defines the course types and intended structure. A catalog entry is not a claim that every detailed lesson, downloadable asset, quiz or answer key has already been authored. Build and verify each course progressively.
