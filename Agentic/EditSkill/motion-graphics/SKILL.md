# Motion Graphics — EditSkill Specialist Module

## Scope
Create titles, kinetic typography, explainers, transitions, lower thirds and branded motion systems.

## Core principles
Use typography as information; design for safe areas and reading time; keep motion purposeful; maintain consistent easing and visual hierarchy.

## Task procedure
Set canvas and frame rate; build type/layout system; animate hierarchy; use restrained easing; preview at delivery size; render with correct alpha/background.

## Quality-control requirements
Check readability, timing, clipping, safe areas, font substitution, aliasing, frame cadence, alpha and output format.

## Required task record
For substantial work, record the brief, assumptions, source assets, rights/consent notes, selected software and version, key settings, steps performed, output paths, validation evidence and unresolved issues.

## Handoff
State inputs consumed, operations completed, output specification, QC result, known limitations and the next required human decision.
