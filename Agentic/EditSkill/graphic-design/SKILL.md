# Graphic Design — EditSkill Specialist Module

## Scope
Create visual communication systems: layout, hierarchy, typography, color, identity assets, posters, thumbnails and production graphics.

## Core principles
Start with audience, message and hierarchy; use licensed fonts/assets; maintain grid, alignment, contrast and brand consistency; prepare editable source files.

## Task procedure
Define brief and sizes; sketch hierarchy; select type and palette; build layout; test at actual viewing size; package fonts/links where licensing permits.

## Quality-control requirements
Check spelling, contrast, alignment, bleed/safe areas, resolution, color mode, font licensing, export and editable-source integrity.

## Required task record
For substantial work, record the brief, assumptions, source assets, rights/consent notes, selected software and version, key settings, steps performed, output paths, validation evidence and unresolved issues.

## Design system and production workflow

### Intake
Confirm audience, message, hierarchy, dimensions, language, medium, accessibility needs, brand constraints, print vendor or digital platform and asset rights.

### Procedure
1. Translate brief into message hierarchy and content inventory.
2. Define grid, spacing, typography, color and component tokens.
3. Build editable vector/raster masters.
4. Check contrast and non-color cues for essential information.
5. Test responsive sizes and localization/text expansion.
6. Verify fonts, stock, icons and generated asset licenses.
7. Prepare screen and print variants with distinct profiles/specs.
8. Preflight bleed, trim, resolution, links, fonts, overprint and transparency.
9. Reopen exports and compare with source.
10. Package editable source, linked assets, license notes and manifest.

### QC
Check spelling, hierarchy, contrast, alignment, safe areas, color profile, export dimensions, font embedding/licensing and downstream print requirements. Do not present generated logo concepts as trademark-cleared or original without review.
