# EditSkill Shared References

This directory holds cross-discipline knowledge used by specialist modules. Keep discipline-specific procedures in their module and curriculum-specific teaching content in the repository course tree.

## Reference groups
- **Media fundamentals:** containers, codecs, compression, raster/vector, sample rate, bit depth, frame rate, color spaces and metadata.
- **Production documentation:** briefs, asset manifests, edit decision lists, storyboards, naming/versioning and handoff records.
- **Interchange:** image, audio, video, subtitle, project and 3D interchange formats; note application/version caveats.
- **Accessibility:** captions, subtitles, contrast, text legibility, audio description and localization checks.
- **Rights and safety:** licensing, consent, privacy, provenance, synthetic-media disclosure and platform restrictions. The repository's `safety-and-licensing/` remains authoritative for project policy.
- **Quality assurance:** technical delivery specs, playback review, device checks and defect reporting. Coordinate with `../../quality-control/`.

## Source policy
Prefer primary documentation from software vendors, standards bodies and format specifications. Record source title, publisher, URL, relevant version/date and the claims it supports. Distinguish verified facts from recommendations. Do not copy proprietary manuals or large copyrighted passages into this repository.

## Maintenance
Review version-sensitive guidance when a tool or format changes. Add a date and affected application/version to each new reference. Avoid duplicate copies of existing course lessons; link to them instead.
