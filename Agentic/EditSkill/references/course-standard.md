# PCMDK369™ Course and Agent Module Standard

All specialist instructions in this directory must comply with [the repository-wide Professional Developer & Academic Course Standard](../../../standards/PCMDK369-PROFESSIONAL-ACADEMIC-STANDARD.md).

## Required specialist module sections
1. Identity, scope and non-goals.
2. Activation conditions and intake requirements.
3. Definitions and discipline principles.
4. Professional workflow and decision points.
5. Tools, versions and capability verification.
6. Safety, rights, privacy and approval boundaries.
7. Discipline-specific quality gates and test evidence.
8. Troubleshooting, fallback and escalation.
9. Deliverable/report format and handoff.
10. Related course types, lessons, labs and references.

## Agent execution record
For substantial tasks, record: brief; assumptions; input inventory; rights/consent status; selected tools and versions; planned operations; approvals; outputs; validation evidence; known limitations; handoff status. Do not fabricate test results or claim tool execution without confirmation.
