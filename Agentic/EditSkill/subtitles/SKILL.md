# Subtitles and Captions — EditSkill Specialist Module

## Scope
Create, synchronize, format, translate and validate captions/subtitles for accessibility and localization.

## Core principles
Preserve meaning and speaker intent; distinguish captions from subtitles; respect reading speed, line breaks, speaker labels and platform formats; human-review speech recognition.

## Task procedure
Transcribe; verify against audio; time cues; segment lines; translate/localize if requested; export formats such as SRT, VTT or platform-specific files.

## Quality-control requirements
Check timing, overlap, reading speed, spelling, speaker IDs, punctuation, line length, encoding, language tags and sync after export.

## Required task record
For substantial work, record the brief, assumptions, source assets, rights/consent notes, selected software and version, key settings, steps performed, output paths, validation evidence and unresolved issues.

State inputs consumed, operations completed, output specification, QC result, known limitations and the next required human decision.
