# Animation — EditSkill Specialist Module

## Scope
Design and produce 2D/3D motion using timing, spacing, poses, rigs, keyframes, interpolation and rendering.

## Activation and intake

Activate this module for 2D or 3D animation planning, keyframe work, rigging, timing, motion refinement, scene animation or render preparation. Coordinate with 3D editing for asset/scene construction and with motion graphics for typography-led animation.

Establish the target duration, frame rate, frame range, delivery dimensions, aspect ratio, playback speed and intended platform. Inventory the scene/project, rigs, models, textures, audio references, fonts and external dependencies. Confirm the animation brief, style references, character/object constraints, approved poses or performances, camera requirements and required render passes. Ask which elements may change and which are locked. Record application/version, renderer and relevant plugin versions only when known. If the scene cannot be opened or the rig is unavailable, provide a diagnostic plan rather than claiming a preview or render was produced.

## Core principles
Plan with thumbnails/animatics; use clear silhouettes and arcs; manage frame rate and interpolation; keep rigs and scenes organized.

## Task procedure
Define duration and frame rate; block key poses; refine timing and spacing; add secondary motion; render previews; review frame-by-frame and in real time.

## Quality-control requirements
Check missing frames, pops, foot sliding, intersections, motion blur, frame rate, render range, alpha and final playback.

## Required task record
For substantial work, record the brief, assumptions, source assets, rights/consent notes, selected software and version, key settings, steps performed, output paths, validation evidence and unresolved issues.

## Animation production workflow

### Planning
Define frame rate, resolution, duration, style/model sheets, timing chart, shot list, output format and approval milestones. Distinguish key poses, breakdowns, in-betweens, holds and exposure.

### Procedure
1. Block silhouettes and key poses.
2. Test timing/spacing at intended playback speed.
3. Add breakdowns, arcs, anticipation, follow-through and secondary action.
4. Check weight, contact and screen direction.
5. Maintain model/character consistency.
6. Clean linework or deformation; organize layers/rig controls.
7. Review motion frame-by-frame and at normal speed.
8. Export image sequence and review movie.
9. Validate frame numbering, alpha, color, frame rate and audio sync.
10. Package editable project, rigs, fonts, linked assets and caches.

### QC
Inspect jitter, pops, shape drift, foot sliding, intersections, missing frames, alpha fringes, frame cadence and project dependencies. Review on intended playback device.
