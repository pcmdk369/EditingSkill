# Image Editing — EditSkill Specialist Module

## Scope
Transform raster images through crop, retouch, masks, layers, compositing, restoration and format conversion.

## Core principles
Preserve source pixels where practical; use layers, masks and adjustment layers; maintain aspect ratio and color profile; document generative or synthetic changes.

## Task procedure
Inspect dimensions, bit depth, alpha and color profile; create a working copy; use selections/masks; compare before/after at fit and 100%; export to target specification.

## Quality-control requirements
Check edges, halos, artifacts, unintended edits, transparency, dimensions, profile, compression and metadata/privacy.

## Required task record
For substantial work, record the brief, assumptions, source assets, rights/consent notes, selected software and version, key settings, steps performed, output paths, validation evidence and unresolved issues.

## Raster image and compositing workflow

### Procedure
1. Confirm intended use: documentary, commercial, portrait, product, creative composite or restoration.
2. Preserve original and record dimensions/profile/metadata.
3. Work non-destructively with layers, masks and adjustment layers.
4. Correct global tone/color before local retouching.
5. Use selections and masks with edge inspection at 100%.
6. Check geometry, text, reflections, anatomy and object continuity.
7. Record material content changes and AI-generated regions.
8. Export to destination-specific format/profile/dimensions.
9. Reopen each output and inspect at actual use size.
10. Package source, linked assets, rights/provenance and QC notes.

### Integrity gates
For factual/documentary use, do not add/remove/relocate content in ways that alter evidence. For product work, do not invent features or alter material appearance. For portraits, respect subject scope and consent. For creative composites, label and contextualize material transformations where needed.
