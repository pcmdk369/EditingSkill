## 01 / Project overview

**Editing Skill™** is a modular learning and production framework for creative editing. It combines a structured, beginner-to-master curriculum with reusable workflows, professional quality standards, and a specialist agent instruction system.

The framework is designed to support two complementary modes:

| Mode | Purpose | Primary entry point |
|---|---|---|
| **Learn** | Study principles, terminology, techniques, and professional practice through sequenced lessons and assessments. | [Curriculum](curriculum/README.md) |
| **Build / Produce** | Plan, execute, review, troubleshoot, automate, and validate creative-production workflows with an AI agent. | [Agentic / EditSkill](Agentic/EditSkill/README.md) |

The system is **tool-independent by design**. Core concepts are taught before software-specific procedures. Application instructions must identify the relevant software, version, platform, and any limitations.

### Core disciplines

- Video editing and cinematic storytelling
- Documentary, interview, commercial, and short-form production
- Photography, image editing, illustration, and retouching
- Audio editing, dialogue, podcast production, sound design, and mixing
- 2D / 3D animation and motion graphics
- Visual effects, compositing, chroma key, and 3D workflows
- Subtitles, captions, accessibility, and localization
- AI-assisted creative production and human-supervised automation
- Professional post-production, finishing, delivery, and archiving

### Use with an AI coding or agent environment

This repository provides Markdown-based instructions; it is not a standalone executable application or a hosted editing service.

1. Open or clone the repository in an AI-enabled development environment.
2. Load the root `SKILL.md` as the primary instruction file.
3. For an agentic editing task, load `Agentic/EditSkill/SKILL.md`.
4. Select the specialist module(s) relevant to the task.
5. Provide the project brief, source assets, target platform, constraints, and desired deliverables.
6. Require the agent to preserve originals, request approval for consequential actions, validate outputs, and report only actions that were actually completed.

Example task brief:

```text
Use the Editing Skill instructions.
Task: create a structured editing plan for the supplied footage.
Target: 60-second vertical social video, 9:16.
Audience: general audience.
Requirements: strong opening, clear story progression, readable captions,
licensed audio, non-destructive workflow, export QC, and delivery notes.
First inspect the assets and propose the workflow. Do not publish or overwrite
source files without explicit approval.
```

## 03 / Learning architecture

Every course is intended to progress through the same eight stages. Advancement is based on demonstrated competence, not simply reading lessons.

| Stage | Level | Competency target |
|---:|---|---|
| 00 | Foundation | Understand media fundamentals, terminology, formats, and safe project setup. |
| 01 | Beginner | Complete guided exercises using core tools and repeatable procedures. |
| 02 | Intermediate | Build structured projects and manage multi-step workflows. |
| 03 | Advanced | Solve complex creative and technical production problems. |
| 04 | Expert | Deliver specialized work against realistic briefs and revision requirements. |
| 05 | Master | Direct creative decisions, design pipelines, and complete capstone work. |
| 06 | AI & Automation | Build responsible, human-supervised assisted and automated workflows. |
| 07 | Professional Practice | Meet delivery specifications, quality gates, documentation, and handoff standards. |

**Course completion principle:** learners must demonstrate knowledge, submit practical evidence, meet the assessment rubric, and explain important creative and technical decisions.

## 05 / Agentic architecture

The `Agentic/EditSkill/` directory is the modular execution layer. A universal router selects specialist instructions according to the user's task.

| Specialist module | Responsibility |
|---|---|
| Video Editing | Timeline, sequence, story, and video-production workflows |
| Audio Editing | Dialogue, waveform, cleanup, synchronization, and audio delivery |
| Image Editing | Raster editing, selections, masks, and image manipulation |
| Photo Editing | Photographic correction, retouching, and restoration |
| Graphic Design | Layout, typography, visual systems, and design assets |
| Animation | 2D / 3D animation principles and production |
| Motion Graphics | Titles, transitions, kinetic type, and motion systems |
| 3D Editing | 3D scene, asset, material, and rendering workflows |
| VFX | Compositing, keying, tracking, and effects workflows |
| Subtitles | Captions, subtitle timing, formats, and localization |
| Color Grading | Color correction, shot matching, and look development |
| AI Editing | Human-reviewed AI-assisted creative workflows |
| Automation | Repeatable operations, batching, and workflow automation |
| Software Tools | Software selection and version-aware procedures |
| Workflows | End-to-end production planning and handoff |
| Quality Control | Technical checks, creative review, and delivery validation |

**Agent entry points:** [Universal router](Agentic/EditSkill/SKILL.md) · [Module directory](Agentic/EditSkill/README.md) · [Shared agent references](Agentic/EditSkill/references/README.md) · [Structural audit](docs/AGENTIC-EDITSKILL-STRUCTURAL-AUDIT.md)

The agent must not imply that it controls an application unless a compatible tool is actually available. It must distinguish a proposed action from an executed action and provide evidence for claimed results.

## 07 / Authoring and quality standard

All 30 course types and all specialist agent modules are governed by the **[PCMDK369™ Professional Developer & Academic Course Standard](standards/PCMDK369-PROFESSIONAL-ACADEMIC-STANDARD.md)**.

A substantial academic lesson should contain:

- Measurable learning outcomes and prerequisites
- Definitions, terminology, purpose, and underlying theory
- Required tools, alternatives, and version/platform notes
- Reproducible procedures and worked examples
- Dry runs, annotated walkthroughs, and guided practice
- Independent assignments and practical evidence
- Troubleshooting, recovery, and common failure modes
- Knowledge checks with answer guidance
- Transparent assessment rubrics and QC checklists
- References, accessibility, rights, safety, and version notes

Reusable authoring resources:

- [Academic lesson template](templates/academic-lesson-template.md)
- [Professional implementation lab template](templates/professional-lab-template.md)
- [Assessment rubric template](templates/assessment-rubric-template.md)
- [Export and delivery template](templates/export-and-delivery.md)

Templates define the expected structure; they must not replace discipline-specific teaching with generic filler.

## 09 / Contribution workflow

Contributions should improve instructional quality, technical accuracy, accessibility, reproducibility, or maintainability.

1. Read the [professional standard](standards/PCMDK369-PROFESSIONAL-ACADEMIC-STANDARD.md) and relevant templates.
2. Identify the exact course, lesson, module, or workflow being improved.
3. Check existing material before adding or replacing files.
4. Keep examples reproducible and identify software/version dependencies.
5. Preserve source assets and document licensing, attribution, and permissions.
6. Add practice, answer guidance, assessment evidence, and quality checks where relevant.
7. Verify internal links, file paths, terminology, and technical claims.
8. Submit a focused pull request describing changes, validation, limitations, and remaining work.

### Development principles

- Fundamentals before application-specific shortcuts.
- Non-destructive workflows and explicit approval for consequential actions.
- No fabricated test results, citations, software behavior, or completion claims.
- Human review for AI-generated or automated creative decisions.
- Respect copyright, licensing, privacy, consent, accessibility, and platform rules.
- Document limitations and unresolved issues clearly.
