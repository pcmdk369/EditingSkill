# Digital Media Fundamentals

## Image
- Raster images store pixels; vector graphics store scalable geometric instructions.
- Resolution describes pixel dimensions; print density and display dimensions are related but distinct.
- Aspect ratio is width divided by height.
- Common formats: JPEG/JPG, PNG, TIFF, WebP, GIF, SVG, RAW and layered project formats.
- Transparency may use an alpha channel; not all formats preserve it.

## Video
- A container packages video, audio, subtitles and metadata.
- A codec encodes/decodes media. Container and codec are not interchangeable.
- Frame rate is frames per second; timecode represents position/duration.
- Bitrate influences file size and can influence quality, but quality also depends on codec, complexity and settings.
- Progressive and interlaced scanning are different display/storage methods.
- Common containers include MP4, MOV and MKV. Common codecs include H.264/AVC, H.265/HEVC, AV1 and ProRes variants.

## Audio
- Sample rate is samples per second; bit depth describes sample precision.
- Channels define spatial arrangement, such as mono and stereo.
- Peak, RMS and LUFS describe different aspects of level/loudness.
- Clipping occurs when signal exceeds the available digital range.

## Color
- RGB is an additive display color model.
- Color space/gamut describes representable colors; transfer function describes encoding of brightness.
- Bit depth affects tonal precision.
- Scopes help evaluate exposure and color objectively.

## Project hygiene
Use consistent names, separate source/project/cache/export folders, preserve originals, back up work, and document project settings.
