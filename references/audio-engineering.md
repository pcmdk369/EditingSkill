# Audio Engineering for Editors

## Signal flow
Source → input gain → cleanup → processing → track level → bus/master → export.

## Core tools
- EQ: changes frequency balance.
- Compression: controls dynamic range.
- Limiter: limits peaks.
- Gate/expander: reduces low-level signal.
- De-esser: controls excessive sibilance.
- Noise reduction: reduces unwanted noise but can introduce artifacts.
- Automation: changes levels/parameters over time.

## Review
Listen on headphones and speakers when possible. Check intelligibility, clipping, noise, phase, sync, music/dialogue balance, fades and delivery loudness. Follow the destination's actual specification rather than assuming one universal LUFS target.
