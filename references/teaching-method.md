# Teaching Method and Lesson Standard

## Learner adaptation
First identify the learner's level, goal, device, available software, language preference, and time. Do not assume access to paid desktop software. Offer equivalent mobile, desktop, and open-source paths when practical.

## Lesson sequence
1. State the learning outcome in plain language.
2. Define every new technical term.
3. Explain the purpose and underlying concept.
4. Show a small worked example.
5. Demonstrate each operation step by step.
6. Include a dry run with expected intermediate results.
7. Give a guided exercise.
8. Give an independent assignment.
9. Explain common errors and recovery.
10. Test understanding and practical performance.

## Explanation style
- Use simple language first, then precise technical vocabulary.
- Separate facts, recommendations, and version-dependent behavior.
- Use tables for comparisons and numbered steps for procedures.
- Explain why a setting matters, not only which value to choose.
- Never skip prerequisites or claim that a learner has mastered a topic without evidence.

## Assessment
Use a mix of knowledge checks, practical output, project-file inspection, and learner explanation. Provide actionable feedback tied to rubric criteria.
