# Export, Containers and Codecs

## Choose an export profile
Determine destination, resolution, frame rate, aspect ratio, codec, container, bitrate/quality mode, audio format, caption delivery, alpha requirements and maximum file size.

## General guidance
- H.264 in MP4 is widely compatible for general delivery.
- HEVC/H.265 and AV1 can improve compression efficiency but compatibility and encoding support vary.
- ProRes and DNxHR are common high-quality intermediate/editing codecs, with larger files.
- PNG/TIFF may suit image sequences; alpha support depends on codec/format.
- WAV is common for uncompressed audio delivery; compressed formats may suit distribution.

## Validation
Check file existence, duration, dimensions, frame rate, audio channels, codec, file size, playback, sync, beginning/end, captions and visual artifacts. Re-export if validation fails.
