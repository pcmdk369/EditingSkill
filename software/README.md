# Software Learning Tracks

The course is tool-independent. Each software track must map application features to transferable editing concepts and identify version-specific differences.

## Video editing
- DaVinci Resolve: media, edit, cut, Fusion, color, Fairlight, deliver.
- Adobe Premiere Pro: ingest, bins, timeline, effects, audio, captions and export.
- Kdenlive / Shotcut: open-source editing fundamentals and export.

## Image and design
- Adobe Photoshop: raster editing, layers, masks, retouching and compositing.
- GIMP: open-source raster editing and image manipulation.
- Adobe Illustrator / Inkscape: vector design and scalable graphics.

## Motion and 3D
- Adobe After Effects: compositing, keyframes, expressions and motion design.
- Blender: 3D modeling, animation, compositing and rendering.

## Audio
- Audacity: waveform editing, cleanup and basic processing.
- REAPER: multitrack editing, routing, effects and automation.
- DaVinci Resolve Fairlight: audio post within a video workflow.

## Mobile
- CapCut and VN: mobile timeline, captions, effects, audio and export.

## Automation
- FFmpeg: inspect, transcode, trim, scale, filter, mix and batch-process media.
- Python scripting: metadata, file operations and reproducible processing where appropriate.

For each application, document supported operating systems, minimum practical hardware, installation source, version, licensing model, limitations, keyboard shortcuts, sample project, and equivalent operations in alternatives. Never assume a feature exists in every version or license tier.
