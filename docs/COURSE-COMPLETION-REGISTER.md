# PCMDK369™ EditingSkill — Course Completion Register

**Purpose:** Track evidence, not assumptions, across all 30 course types.  
**Rule:** “Outline exists” does not mean “course complete.” A course is complete only after lessons, labs, assessment, capstone, references and review evidence satisfy the repository standard.











## Required status vocabulary
- **Planned:** scope identified; content not yet authored.
- **Outlined:** course outline exists.
- **Authored:** required learning resources drafted.
- **Reviewed:** academic, technical, editorial, rights and accessibility checks recorded.
- **Validated:** reproducibility or technical checks have evidence.
- **Complete:** all required resources and gates pass.
- **Blocked:** dependency or decision prevents progress.

## Mandatory evidence per course
1. Course outline with outcomes, prerequisites, levels and software alternatives.
2. Learner-facing textbook/notes or equivalent complete instructional content.
3. Detailed lessons across the mapped progression.
4. Practical labs with environment/version, inputs, expected artifacts and tests.
5. Knowledge assessment and answer guidance.
6. Capstone brief, submission manifest and rubric.
7. Rights, safety, privacy and accessibility notes.
8. Internal-link and formatting checks.
9. Technical/editorial review record with reviewer/date.
10. Completion decision supported by evidence.
