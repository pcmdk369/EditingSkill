# Export and Delivery Checklist

## Specification
- [ ] Destination and audience confirmed
- [ ] Dimensions and aspect ratio confirmed
- [ ] Frame rate confirmed
- [ ] Container and codec confirmed
- [ ] Quality/bitrate target confirmed
- [ ] Audio format/channels confirmed
- [ ] Caption/subtitle format confirmed
- [ ] File-size and naming requirements confirmed

## Review
- [ ] Full export played from beginning to end
- [ ] No missing media or black frames
- [ ] No unintended glitches, freezes or dropped frames
- [ ] Audio sync and levels checked
- [ ] Captions checked for timing and spelling
- [ ] Titles and graphics within safe areas
- [ ] Color and exposure checked
- [ ] Correct ending, fades and duration
- [ ] File metadata and playback compatibility checked

## Delivery
- [ ] Correct version and filename
- [ ] Project/source handoff included if agreed
- [ ] Required licenses/attributions documented
- [ ] Delivery manifest and notes included
- [ ] Archive/backup confirmed
